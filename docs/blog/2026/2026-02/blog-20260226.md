## Summary

XerahS released v0.18.4–v0.18.8 with Windows capture fixes, clipboard (Avalonia for desktop, Win32-only for CLI), and multiple release bumps. XIP0042 (ImageEditor SkiaSharp GPU effects) and XIP0041 (Native AOT) task docs were added; XIP0042 sync and dual-host compatibility noted. **ShareX.ImageEditor** added ActiveToolName/tooltip binding, Flatten keyboard shortcut, opaque grays for icon foreground, ColorPickerDropdown border hole and label; XerahS also updated settings/task panels to maximize free space and fixed UseModernCapture default with DXGI verification logging.
