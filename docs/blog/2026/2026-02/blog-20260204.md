## Summary

XerahS added auto-destination uploader behaviour, clipboard upload routing, a cross-platform secrets store, and new plugins (Paste2, GitHub Gist). The day also brought secret-store diagnostics, UI/control audit updates, and WIP Linux Wayland screen recording improvements, setting the stage for v0.8.0.

## Features

- **Auto destination and clipboard upload**: Added auto-destination uploader and clipboard upload auto-routing so captures and clipboard content can be sent to the configured destination without an extra step (`f3abe81d`, `6527590f`).
- **Clipboard in capture phase**: Allowed clipboard payloads in the capture phase so paste-from-clipboard flows are supported end-to-end (`a2e336f7`).
- **Cross-platform secrets store**: Implemented a cross-platform secrets store and secret-store diagnostics so uploader credentials and tokens can be stored and inspected consistently across OSes (`c2b81051`, `f626f094`).
- **Paste2 and GitHub Gist plugins**: Added Paste2 and GitHub Gist plugins so users can upload text and snippets to these services (`194113bd`, `3ec377db`).
