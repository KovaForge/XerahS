# XerahS Daily Blog Draft - 2026-02-27

Date: 2026-02-27
Time Zone: UTC+8
Status: Draft

## Summary

XerahS shipped v0.18.9 with WinForms removal, daemon bundling hardening, and release automation; v0.18.10 and v0.18.11 followed with clipboard and capture fixes. **ShareX.ImageEditor** improved effect dialogs (Skew, Rotate3D, ReplaceColor, Resize Canvas), annotation handling during image ops, and TFM reduction to net9/net10; XIP0042 and XIP0043 task docs were updated and moved to complete where applicable.

## Features

- **ShareX.ImageEditor: Effect and dialog improvements**: Added AutoResize option to Skew and Rotate3D effects, extended rotate range to ±360°, added color picker to Resize Canvas dialog, improved Active Tool Icon display and tooltip binding, and added ReplaceColorDialog color picker UI and selective color optimization (`b43dca4`, `1b44e5b`, `7c969f4`, `ccc196c`, `07a4c31`, `4b0985a`, `a876e6b`, `bfb3cfd`).
- **ShareX.ImageEditor: Annotation and image ops**: Transform annotations during image operations, invoke AnnotationsRestored after image ops, and use annotation bounds to position visuals so annotations stay correct after resize/rotate/skew (`1ff7b20`, `b8b5e5a`, `0f6aafa`).
- **XerahS: XIP0043 completion**: Created XIP0043 task doc (Remove WinForms and Harden Cross-RID Daemon Bundling) and moved it to the complete folder (`e2f0a82a`, `906ff4ed`).

## Fixes

- **XerahS: WinForms removal and Windows platform**: Removed WinForms dependency from the Windows platform so the app no longer pulls in WinForms for UI (`c3429d21`).
- **XerahS: Clipboard and capture**: Marshalled Avalonia clipboard access to the UI thread to avoid cross-thread issues; corrected flipped monitor orientation in DXGI capture (`5068ebb5`, `a616a645`).
- **XerahS: Release and update flow**: Prevented startup crash from update dialog owner; enforced OS/arch update asset selection; avoided SIGPIPE in archive validation checks (`13a132f3`, `e8df932c`, `d0f4fb21`).
- **ShareX.ImageEditor: Loaded event**: Used Loaded event and removed IsLoaded checks for more reliable dialog and control lifecycle (`37db6b3`).

## Build and Tooling

- **XerahS: v0.18.9 release and CI**: Released v0.18.9; added changelog update automation script; validated release assets and RID metadata; hardened daemon bundling across desktop RIDs; failed fast for Linux publish and validated package payload; updated ImageEditor submodule for TFM simplification; skipped app-driven plugin build in solution builds (`fd0c8d3a`, `8d448f32`, `f5e82aec`, `76d79739`, `41bce225`, `535d6ca4`, `c647917c`).
- **XerahS: Version and links**: Updated CHANGELOG and Links.cs; bumped ImageEditor submodule (`513a7825`, `a747b707`, `87aab835`, `3e7e1de6`).
- **ShareX.ImageEditor: TFM and docs**: Reduced ImageEditor target frameworks to net9/net10; renamed ShareX.Editor to ShareX.ImageEditor in README (`68fa534`, `4c0148e`).
