# XerahS Daily Blog Draft - 2026-02-16

Date: 2026-02-16
Time Zone: UTC+8
Status: Draft

## Summary

XerahS shipped v0.15.7 with ImageEditor context menu and theme fixes (ContextMenu/MenuFlyout, RenderTargetBitmap and annotation layer capture fixes), mobile TimeZoneInfo serialization fix, and ImageEditor submodule config (update=rebase). **ShareX.ImageEditor** added ShareX theme support (ShareXLight, ShareXDark), hybrid rendering (core draws only bitmap), rotation for text annotations, and theme resource usage; XerahS merged theme sync and platform detection.

## Features

- **ShareX.ImageEditor: Theming**: Add ShareXLight and ShareXDark themes; add theming support with ShareX theme; use dynamic theme resources for editor UI; add disabled background brush to themes; reorder theme dictionaries in ShareXTheme.axaml; use theme resource for checkered background; add translucency to theme and tweak toolbar layout (`267c3a5`, `fd2ebed`, `4b6ce0a`, `f5dc604`, `7eecbc4`, `9e92b54`, `3e2f135`).
- **ShareX.ImageEditor: Text rotation and hit testing**: Add rotation support for text annotations; handle rotated annotations in hit testing (`ed6d542`, `f811bc9`).
- **ShareX.ImageEditor: Hybrid rendering**: Adopt hybrid rendering; core draws only bitmap (`3e8e676`).
- **XerahS: Theme sync**: Sync app & ImageEditor themes, add platform detection (`71fa3e16`).

## Fixes

- **XerahS: Context menu**: Reinstate ContextMenu with custom styles for theme compatibility; use MenuFlyout for editor context menu (`8c1a6ab`, `f811bc9`).
- **XerahS: Annotation layer capture**: Dispose RenderTargetBitmap after pixel copy; skip forced Measure/Arrange when canvas is already at correct size; hide inline TextBox during annotation layer capture; use direct pixel copy instead of PNG round-trip in RenderAnnotationLayer (`af35c744`, `b3034bec`, `f3e39084`, `bb862c4b`).
- **XerahS: Mobile**: Handle TimeZoneInfo serialization in mobile upload settings (`a8351530`).
- **XerahS: Submodule**: Add update=rebase to ImageEditor submodule configuration; resolve ImageEditor submodule reference issue (`6d905069`, `e4815df9`).

## Build and Tooling
