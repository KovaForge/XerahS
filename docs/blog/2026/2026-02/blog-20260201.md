Date: 2026-02-01

## Summary

Today pushed XerahS toward a more modern capture and task experience: AVIF/WebP landed as first-class image formats, Task Settings got a dedicated Image/Video UX redesign, and Linux region capture and hotkeys were hardened via XDG Portal. Smaller UX and packaging tweaks rounded out the day.

## Features

- Added **AVIF and WebP image format support** (XIP0025), including UI integration and enum clean-up, so users can capture and export in modern, space-efficient formats.
- Shipped a **Task Settings UX redesign** with dedicated Image and Video tabs (XIP0026), making it easier to reason about capture and recording workflows without wading through a single giant panel.
- Hid the **main window during navbar/tray-triggered captures**, reducing visual noise and the risk of accidentally capturing the app chrome itself.

## Fixes

- Fixed duplicate `EImageFormat` enum values and updated the UI to properly surface AVIF/WebP choices, preventing subtle bugs and confusion in format selection.
- Fixed Linux region capture and hotkey initialization and integrated **XDG Portal** for Wayland/Linux screen capture (including Debian tar compatibility fixes), making capture feel much more reliable across distros.
- Tweaked the **update dialog** so action buttons sit below the text, matching common dialog conventions and improving readability.

## Build and Tooling

- Removed a mistakenly committed plugin package from the repo history and tightened packaging practices around plugins.
- Renamed the “Website” entry to **XerahSWebsite** and added an Issues link, aligning the navigation and metadata with the project’s current branding and support flows.
- Continued to expand Task Settings documentation with a dedicated UX redesign doc, capturing design intent for future iterations.
