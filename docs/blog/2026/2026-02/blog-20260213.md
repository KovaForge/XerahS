# XerahS Daily Blog Draft - 2026-02-13

Date: 2026-02-13
Time Zone: UTC+8
Status: Draft

## Summary

XerahS added mobile Android and iOS MVPs with Share-to-XerahS and Share Extension support, mobile-friendly Amazon S3 configuration UI, and wiring for Editor Copy to Clipboard and ShowAfterCaptureWindow. Auto destination fallback, backup/secrets store, and watch-folder MOV-to-MP4 conversion landed. **ShareX.ImageEditor** improved effect preview (clean source image, avoid feedback loop), and arrow rendering was unified between Editor and Region Capture (XerahS).

## Features

- **XerahS: Mobile MVP**: Add Mobile Android MVP with Share-to-XerahS upload support; add Mobile iOS MVP with Share Extension support; add mobile-friendly Amazon S3 configuration UI with settings navigation (`87463723`, `03698c60`, `78a488e1`).
- **XerahS: Custom uploader UI**: Adds Custom Uploader support to Mobile UI (PR); Redesign Amazon S3 config to mimic Custom Uploaders UI (PR) (`08604ee5`, `6bacd05e`).
- **XerahS: Secrets and backup**: Make secrets store machine-specific; backup all JSON files and add machine name to backup filename (`55a32d09`, `c6185422`).

## Fixes

- **XerahS: Auto destination and settings**: Auto destination now falls back to File category when Image/Text uploaders fail; persist ShowAfterCaptureWindow when unchecked in After Capture window; auto destination now tries multiple uploaders with fallback logic; wire mobile S3 config to InstanceManager upload pipeline; wire up Editor Copy to Clipboard and fix ShowAfterCaptureWindow persistence; track attempted uploaders to avoid retrying same instance; use async save for ShowAfterCaptureWindow setting (`c06f17f4`, `9a04c9d7`, `72079e69`, `44c316b3`, `a3a581de`, `a576e78a`, `c06f17f4`).
- **XerahS: Mobile and watch-folder**: Convert watch-folder MOV files to MP4; mobile plugin integration and upload pipeline fixes (`27f6fec4`, `02087fb6`).
- **XerahS: Owner window**: Pass owner window to media tool windows to fix z-order issue (`a30810d7`).
- **XerahS: Region capture and editor**: Persist region annotation options and track ImageEditor main; refactor MonitorTest and Ruler platform abstractions; add annotation options persistence for RegionCapture (`2cc8fa71`, `554099c6`, `7e82df3a`).
- **ShareX.ImageEditor: Effect preview**: Use clean source image before applying effect; avoid preview feedback loop; use pre-effect image (`24fb99d`, `5112d21`, `aa5d935`).
- **XerahS (from ImageEditor sync):** Unify arrow rendering between Editor and Region Capture (`aa5d935`).

## Build and Tooling

- **XerahS: Docs and version**: Add XIP writing skill guide; consolidate git and versioning guidance into workflow skill; support legacy editor preset namespaces and sync version workflow; consolidate v0.14.x patches into v0.14.0 in CHANGELOG; remove BOM from build README encoding (`70479c4e`, `4a09c192`, `0e689c5f`, `b7aef8cd`, `7d67bb52`).
