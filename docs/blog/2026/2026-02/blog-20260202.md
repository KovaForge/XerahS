# XerahS Daily Blog Draft - 2026-02-02

Date: 2026-02-02
Time Zone: UTC+8
Status: Draft

## Summary

This was a big Linux and cross-platform hardening day: Wayland portal recording and screenshot support matured, Linux dark mode and active window capture were improved, and macOS gained a native app menu. The team also tidied build configuration, docs, and the changelog while bumping versions to reflect the new capabilities.

## Features

- Added **Linux dark mode support and theme settings**, making XerahS better match the look-and-feel of GNOME, KDE, and other modern desktops.
- Implemented **Wayland/Hyprland screenshot support using grim+slurp**, giving Wayland users a native-feeling screenshot path in addition to portal-based flows.
- Switched **Wayland recording** to use the ScreenCast portal on supported desktops, bringing recording behavior in line with modern sandboxed environments.
- Added a **native macOS app menu** with XerahS branding, improving integration with macOS conventions and menus.
- Introduced a **recording-aware tray icon** with pause/abort controls and moved the recording border window logic into `TrayIconHelper`, making recording control more discoverable.

## Fixes

- Fixed Linux active window capture, including handling for complex window hierarchies and absolute screen coordinates, so active-window captures behave more like their Windows counterparts.
- Fixed Linux clipboard backend selection and improved Linux hotkey error handling, reducing crashes and confusion when configuring shortcuts.
- Fixed Wayland portal D-Bus signal signatures and portal response parsing, and added capability checks and fallbacks to make Wayland capture more robust in the face of portal quirks.
- Skipped Windows platform builds on non-Windows machines and allowed building Windows-targeted tests on non-Windows, reducing CI friction and local build surprises.

## Build and Tooling

- Updated the README build instructions and **populated the full changelog history**, aligning documentation with the current build and release process.
- Bumped versions to 0.7.5, 0.7.6, and 0.7.7 over the course of the day to reflect Wayland, tray, and fix work, and updated workflow editor diagnostics.
- Added `linux_debug_prompt.md` and a runtime error log doc to help contributors diagnose issues on Linux more effectively.
- Fixed build by adding missing `CommunityToolkit.Mvvm` references and correcting project references, unblocking further work.
