# XerahS Daily Blog Draft - 2026-04-14

Date: 2026-04-14
Time Zone: UTC+8
Status: Draft

## Summary

2026-04-14 was a heavy iOS-focused day in XerahS, with the team expanding hosted `.sxcu` importing, tightening S3 upload compatibility, and refreshing the mobile interface with a Liquid Glass pass. The same day also cleaned up markdown encoding across the repository, added hygiene checks to catch mojibake and BOM issues earlier, and rolled the `ShareX.ImageEditor` submodule forward to its `v0.2.0` release.

## Features

- XerahS: Added a hosted `.sxcu` import flow on iOS so uploader configurations can be pulled into the mobile app from linked sources instead of relying only on local clipboard content.
- XerahS: Revamped the iOS UI with a new Liquid Glass visual treatment across loading, upload, history, and settings screens, including a shared `GlassUI` component layer to support the redesign.

## Fixes

- XerahS: Improved iOS upload diagnostics and S3 endpoint handling so failures surface more useful detail while custom endpoints and result reporting behave more consistently.
- XerahS: Matched the iOS S3 uploader's dotted-bucket handling and signing timestamp behaviour with desktop and AWS-compatible expectations, reducing provider-specific upload failures.
- XerahS: Added better diagnostics around iOS `.sxcu` clipboard imports so configuration parsing problems are easier to identify and recover from.
- XerahS: Updated the desktop provider explorer bindings and aligned the schema-driven filter catalog tests with the upstream ImageEditor `Effect` naming so the Avalonia UI and tests stay in sync.
- XerahS: Improved the iOS share-extension upload and `.sxcu` import flow so uploads handed off from the share sheet and app startup state are coordinated more reliably.

## Build and Tooling

- XerahS: Repaired markdown encoding across root docs, build docs, developer guidance, status notes, and blog/report content to remove mojibake and normalize UTF-8 handling.
- XerahS: Added markdown mojibake and BOM checks to both local pre-commit hooks and the `markdown-hygiene` GitHub Actions workflow, then tightened the workflow triggers so the checks only run when relevant markdown or tooling files change.
- XerahS: Consolidated unreleased changelog content under the `v0.22.2` heading so the release notes reflect the full range since `v0.21.2`.
- XerahS: Updated the `ShareX.ImageEditor` submodule to `v0.2.0`.
- ShareX.ImageEditor: Published the `v0.2.0` version bump and changelog covering the Avalonia 12 and .NET 10 single-target migration, annotation sidecar work, new effects, AVIF support, and the SkiaSharp API transition that XerahS now consumes through the submodule update.
