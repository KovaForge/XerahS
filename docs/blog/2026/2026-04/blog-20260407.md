- XerahS: Fixed `AVLN2000` — invalid binding path syntax in `OnboardingWizardWindow.axaml` — resolving the Avalonia binding analyzer error in the newly completed wizard (`be6b7a2d`).

- XerahS: Removed deprecated `_Onboarding_BACKUP` directories left over from earlier onboarding iterations (`bee92a84`).
- XerahS: Prevented infinite recursion in `UploadJobProcessor.TryUploadWithFallback` — a regression that could cause the uploader to loop indefinitely on certain failure paths (`adc18dea`).
- XerahS: Fixed generic uploader file uploads to use `info.FileName` instead of a raw path, ensuring consistent naming across uploaders (`d2d45d32`).
