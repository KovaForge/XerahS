# XerahS Daily Blog Draft - 2026-04-09

Date: 2026-04-09
Time Zone: UTC+8
Status: Draft

## Summary

April 9 is the v0.22.0 release day — the culmination of the Avalonia 12 upgrade, the completed onboarding wizard (XIP0060), and several weeks of stabilization work across the board. XerahS shipped with grouped and versioned library information in the About dialog, fixed screenshot uploader resolution handling, resolved duplicate DevTools attachment crashes in DEBUG builds, and continued advancing the XIP0068 annotation re-editing spec through design review. ShareX.ImageEditor's submodule was caught up to the latest upstream ShareX changes, and the editor continued its own Avalonia 12 migration with arrow-tail rendering fixes for step annotations.

## Features

- XerahS: Grouped loaded libraries by category in the About dialog, making the dependency inventory easier to navigate (`ab8a6034`).
- XerahS: Extended the About dialog to display version information for all loaded assemblies, giving contributors and power users precise version visibility (`246a37f7`).
- XerahS: XIP0068 (re-editing saved annotations) advanced through design review, with a critique round and updated design document adding precision to the specification (`fc3e71c1`, `9fd13117`, `a2fc92bd`).
- ShareX.ImageEditor: Added `Arrow tail style support` for `NumberAnnotation`, completing the tail-style family across step, speech balloon, and number annotation types (`80b4749`).
- ShareX.ImageEditor: Deferred rendering of step annotation arrow tails until the user drags them, avoiding invalid geometry on initial render (`9c65902`).
- ShareX.ImageEditor: Fixed step annotation arrow tail rendering to use proper shaft geometry instead of an incorrect shape (`e35a1c4`).

## Fixes

- XerahS: Fixed DevTools double-attachment in DEBUG builds. `App.Initialize` was independently calling `WithDeveloperTools()` in DEBUG, causing Avalonia to throw because multiple DevTools attachments are not supported. Consolidated the call to `Program.BuildAvaloniaApp()` behind a `#if DEBUG` gate (`f1c859e9`, `1cbf5afb`).
- XerahS: Restored screenshot uploader resolution handling — a regression had caused screenshot uploaders to ignore the captured image resolution (`c32ab11e`).
- XerahS: Enabled Avalonia dev tools and fixed a `Sample.png` bitmap leak in the editor startup path (`51f23270`).
- ShareX.ImageEditor: Corrected the icon system in XIP0067 to use Lucide icons instead of `Material.Icons.Avalonia`, aligning with the documented design decision (`106bd3c6`).
- ShareX.ImageEditor: Aligned ImageEditor Avalonia version with XerahS, upgraded `Tmds.DBus`, and made `Sample.png` loading asynchronous to avoid blocking the UI thread on startup (`e9ceb393`).
- ShareX.ImageEditor: Fixed `StepControl` rendering bounds and reverted to Avalonia 11.3.13 to match XerahS `develop` at the time, then immediately re-upgraded to 12.0.0 once XerahS confirmed its own Avalonia 12 upgrade (`2ad6297`, `9f833c4`, `197e772`).

## Build and Tooling

- XerahS: Caught up ShareX.ImageEditor submodule to `ShareX@c6e3c5260`, bringing in the latest upstream ShareX changes including interaction cache, spotlight overlay, and the step/speech balloon annotation styling work (`f361802d`, `a3e3cc85`, `b168ea8`).
- ShareX.ImageEditor: Merged pull request #16 from `ShareX/develop`, incorporating the full step-tail-arrow-init-gate branch with deferred tail rendering and shaft geometry fixes (`c95580e`).
- ShareX.ImageEditor: Merged pull request #15 from `codex/step-tail-arrow-init-gate`, bringing in the arrow tail style support for number annotations (`c95580e`).
- XerahS: Added XIP0065, XIP0066, and XIP0067 design documents formalizing the Avalonia 12 upgrade decisions, icon system choice, and related architectural changes (`b574e02d`).
- XerahS: Aligned all XIP documentation with the finalized Avalonia 12 release decisions (`b4c43b5e`).

## Notes

- April 9 is the v0.22.0 release day, encompassing the Avalonia 12 upgrade, the completed onboarding wizard, and the MCP Phase 2 groundwork laid over the preceding days.
- ShareX.ImageEditor went through a three-step Avalonia migration dance on this day: upgrade to 12.0.0, immediate revert to 11.3.13 to match XerahS `develop`, then re-upgrade to 12.0.0 once XerahS confirmed its own target. This reflects the tight coupling between the submodule and host repo during a major framework version bump.
- The duplicate DevTools attachment fix (`1cbf5afb`) was a DEBUG-only crash that would not have appeared in release builds but would have been a blocker for any developer using DevTools during development.
- XIP0068 on annotation re-editing is now through design review and approaching implementation readiness.
