## Summary

2026-04-30 was a feature-and-hardening day in XerahS that combined desktop reliability fixes with a major push on iOS UX and destination configuration portability across desktop and mobile. The day started with path, uploader, toast, backup, OCR, and Windows capture fixes, then moved into plugin extraction hardening and several macOS capture and overlay repairs before expanding into iOS share-extension work, a native SwiftUI shell transition, Home/history consolidation, a new About screen, encrypted destination-config export on desktop, and mobile import support on both Android and iOS.

All verified same-day commits came from the main XerahS repository. `ShareX.ImageEditor` had no author-dated commits in its local submodule history for this UTC+8 window, and `XerahS.Editor` had no matching commits on the checked remote `develop` history.

## Features

- XerahS: Added encrypted destination configuration export from the desktop app, including new dialog and settings wiring so uploader and destination setups can be packaged for transfer more safely.
- XerahS: Added destination configuration import on mobile, including Android manifest and data-layer support plus iOS app-state and root-view integration, so desktop-exported configuration bundles can be consumed on mobile devices.
- XerahS: Moved the iOS app onto a more native SwiftUI shell and merged history into the Home experience, simplifying the mobile navigation structure while keeping recent activity closer to the main upload workflow.
- XerahS: Added a dedicated iOS About screen and connected it into the mobile settings navigation flow.
- XerahS: Added a CLI verification command and tests for native macOS crosshair capture so the recent macOS region-capture work has a repeatable validation path.

## Fixes

- XerahS: Fixed assistant OCR history path normalization, uploader file-type routing normalization, FTP retry directory handling, zero-duration toast fade startup, weekly settings backup creation, and onboarding OCR language refresh cleanup.
- XerahS: Fixed DXGI crop rectangle conversion and added Windows capture tests so cropped modern-capture results map correctly to the expected screen region.
- XerahS: Notified settings observers after uploader configuration saves so the rest of the app can react immediately when upload settings change.
- XerahS: Hardened plugin package extraction and added plugin security coverage to better validate packaged plugin content before it is accepted.
- XerahS: Fixed editor close-session completion so editor shutdown flows finish cleanly instead of leaving the session state incomplete.
- XerahS: Fixed macOS overlay viewport mapping, prevented chained macOS region selectors, and stabilized native macOS crosshair capture to reduce regressions in the region-capture flow.
- XerahS: Fixed uploads from the iOS share extension by adding dedicated upload service plumbing, entitlement updates, and clearer feedback so shared content can complete the same upload path more reliably.
