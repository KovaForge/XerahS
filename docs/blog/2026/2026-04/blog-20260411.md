# XerahS Daily Blog Draft - 2026-04-11

Date: 2026-04-11

Status: Draft

## Summary

April 11 turned the onboarding wizard from a rough debug target into a more coherent first-run flow, with state fixes, rendering fixes, uploader configuration, hotkey selection, and a race fix that moves the first-run trigger to the main window open path. The day also landed editable annotation sidecar support across XerahS and ShareX.ImageEditor, refreshed the XIP and MCP documentation set, and consolidated several repo automation skills around release, build, changelog, and XIP maintenance guardrails.

## Features

- XerahS: Reworked the onboarding wizard flow around dedicated step views, uploader configuration support, completion actions, and a cleaner shell for progressing through the setup experience (`4ba7d3c3`).
- XerahS: Wired onboarding hotkey selection through the hotkey step view model and the shared `HotkeySelectionControl`, replacing the earlier inline hotkey editing path (`5c598d5b`).
- XerahS: Added editable annotation sidecar preservation so saved captures can retain re-editable annotation project data alongside the final image and expose history actions for reopening editable annotations (`9112999a`).
- ShareX.ImageEditor: Added project-file persistence and session result plumbing for editable annotation sidecars, giving XerahS a committed ImageEditor-side format and save/load surface for the new re-edit workflow (`45cf1de`).
- XerahS: Added XIP0069 and XIP0070 proposals for after-capture OCR integration and user research around top screen capture needs (`5ef03e41`).

## Fixes

- XerahS: Repaired onboarding step state flow by tightening validation and step view model behavior across hotkey, OCR, save location, upload, complete, and welcome steps (`b87caa39`).
- XerahS: Repaired onboarding wizard rendering by simplifying the window markup, adjusting the progress indicator, and moving first-run display onto an async app path (`2ef18e36`).
- XerahS: Forwarded onboarding debug arguments through the debug launch script so the dedicated launcher mode can actually reach the app during local testing (`6d5e236e`).
- XerahS: Fixed editable-annotation detection so history items can fall back to the default sidecar path convention when explicit sidecar metadata is not present (`4d5d99c8`).
- XerahS: Refreshed history thumbnails after annotation re-editing so the history view reflects the edited image instead of leaving stale preview state behind (`0b9b0f8f`).
- XerahS: Removed save-location quick select shortcuts from the onboarding save location step as part of reducing confusing or redundant first-run choices (`2cf84f27`).
- XerahS: Fixed an onboarding trigger race by moving the startup trigger out of `App.axaml.cs` and into `MainWindow.OnWindowOpened`, alongside the 0.22.1 version bump (`7921fd4b`).

## Build and Tooling

- XerahS: Added tests for editable annotation sidecars, including history editor launch coverage and project-file service coverage (`aa577153`).
- XerahS and ShareX.ImageEditor: Renamed the editable annotation sidecar format to use the `.xann` convention in docs, runtime paths, tests, and ImageEditor persistence types (`f71c0ed4`, `42f27c9`).
- XerahS: Refreshed the MCP usage guide after the MCP runtime work so the documentation reflects current setup and usage expectations (`94a09599`).
- XerahS: Normalized XIP references from `XIP-NNNN` to `XIPNNNN` across the active docs touched by the current proposal work (`7c730871`).
