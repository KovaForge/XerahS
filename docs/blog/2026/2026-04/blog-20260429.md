# XerahS Daily Blog Draft - 2026-04-29

Date: 2026-04-29
Time Zone: UTC+8
Status: Draft

## Summary

2026-04-29 was a broad release-readiness and stabilization day in XerahS, covering uploader normalization, CLI workflow expansion, mobile store preparation, Android uploader parity, plugin publishing, and several macOS, Linux, indexing, and file-handling fixes. The day moved from defensive correctness fixes in uploaders, plugins, hotkeys, and validation into iOS App Store prep, Android upload configuration work, and a late round of macOS overlay repairs that were merged back into `develop` before the UTC+8 day closed.

All verified same-day commits came from the main XerahS repository. `ShareX.ImageEditor` and the available local `_tmp_XerahS.Editor` checkout had no author-dated commits in this UTC+8 window.

## Features

- XerahS: Added file-forced CLI uploads and an OpenClaw CLI manifest so automation and contributor workflows can drive explicit file uploads more directly.
- XerahS: Added the iOS App Store submission setup, privacy manifests, export-compliance declarations, Keychain-backed uploader secret storage, updated identifiers, automatic signing attributes, and screenshot assets to move the mobile app closer to store submission.
- XerahS: Added Android Play submission guidance, API 35 targeting, backup-exclusion rules, iOS-style S3 endpoint options, SXCU custom uploader support, and share-upload result copying so Android uploader behavior moved closer to the iOS experience.
- XerahS: Added a macOS capture sound setting so desktop capture behavior can be configured explicitly instead of relying only on fallback handling.
- XerahS: Published the Pixelfox registry package and refreshed macOS release assets as part of the day’s packaging and release-preparation pass.

## Fixes

- XerahS: Hardened MCP test adapter asset metadata and annotation parameter parsing so automation-facing tests and annotations fail earlier and more predictably when metadata drifts.
- XerahS: Fixed headless editor unavailable results, uploader fallback after primary failure, uploader deletion metadata persistence in history, Nextcloud server URL normalization, FTP host normalization, and Imgur client ID normalization, reducing fragility across several upload paths.
- XerahS: Fixed plugin package install root creation so plugin installation can create and validate its destination more reliably before extraction.
- XerahS: Fixed workflow hotkey retry behavior after stale failed identifiers, preventing blocked reruns after previous failures.
- XerahS: Fixed video thumbnail grid column validation and sticky toast validation to tighten UI-side guard rails before follow-up work runs.
- XerahS: Improved the iOS share upload flow and fixed CLI upload bootstrap and JSON output behavior so both mobile-share and desktop-command upload paths are less brittle.
- XerahS: Fixed macOS region selector preference and exclusivity behavior, restored and then reapplied macOS region overlay alignment, aligned the macOS capture sound fallback, normalized clipboard file-drop paths, and cleaned up notification timeout processes.
- XerahS: Fixed unique file path suffix overflow, normalized indexer extension filters, corrected indexer negative-depth traversal, and hardened Sway Wayland rectangle parsing to improve file handling, indexing, and Linux window-query reliability.

## Build and Tooling

- XerahS: The iOS and Android commits were heavily packaging-oriented, covering signing, identifiers, screenshots, privacy metadata, backup rules, target API alignment, and release-check documentation rather than isolated runtime-only feature work.
- XerahS: Documentation updates for the April 28 and April 29 engineering posts, plus the Android release-build checklist work, landed in the same UTC+8 window and were later merged back into `develop` alongside the macOS overlay follow-up.
- XerahS: Several merges from `upstream/develop` and one merged pull request were part of the same stabilization flow, showing that release prep, fixes, and documentation were being integrated continuously through the day.
