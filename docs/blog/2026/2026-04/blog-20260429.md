## Summary

2026-04-29 was a broad platform and release-readiness day in XerahS, spanning uploader stabilization, CLI improvements, mobile store preparation, Android upload-feature parity, plugin publishing, and cross-platform capture correctness fixes. The day opened with headless-editor, uploader, plugin-install, hotkey, and thumbnail validation work, then expanded into iOS App Store readiness, Android Play and uploader-option alignment, macOS capture and overlay follow-ups, and later CLI, indexer, clipboard, and Linux window-query hardening.

All verified same-day commits came from the main XerahS repository. `ShareX.ImageEditor` had no author-dated commits in this UTC+8 window, and no local `XerahS.Editor` checkout was available in the workspace to review for same-day activity.

## Features

- XerahS: Added file-forced CLI uploads and an OpenClaw CLI manifest, extending contributor-facing command-line workflows and making explicit file upload paths easier to drive from automation.
- XerahS: Added iOS App Store submission setup assets, privacy manifests, export-compliance declarations, Keychain-backed uploader secret storage, updated identifiers, automatic signing attributes, and screenshot assets to move the mobile client closer to store submission readiness.
- XerahS: Added Android Play submission guidance, API 35 targeting, backup-exclusion rules, iOS-style S3 endpoint options, SXCU custom uploader support, and share-upload result copying so the Android app moved closer to the iOS uploader feature set.
- XerahS: Added macOS capture sound configuration so desktop capture behavior can be configured explicitly instead of relying on a single fallback path.
- XerahS: Published the Pixelfox registry package entry and refreshed macOS release assets as part of the day's packaging and release-preparation work.
- XerahS: Refreshed the 2026-04-28 and 2026-04-29 daily blog drafts and added Android release-check documentation so the repository's engineering journal and release notes stayed synchronized with the implementation work.

## Fixes

- XerahS: Hardened MCP test adapter asset metadata and annotation parameter parsing so tool-facing tests and automation inputs fail earlier and more predictably when metadata or arguments drift.
- XerahS: Fixed headless editor unavailable results, uploader fallback after primary failure, Nextcloud server URL normalization, FTP host normalization, and Imgur client ID normalization, reducing configuration fragility across several upload paths.
- XerahS: Fixed plugin package install root creation so plugin installation can reliably materialize its destination before extraction and validation.
- XerahS: Fixed workflow hotkey retry behavior after stale failed identifiers, preventing repeat launches from getting blocked by outdated failure state.
- XerahS: Fixed video thumbnail grid column validation and sticky toast validation, tightening UI-side input guarding before follow-up work runs.
- XerahS: Improved the iOS share upload flow and fixed CLI upload bootstrap and JSON output behavior so both mobile-share and desktop-command upload paths are less brittle.
- XerahS: Fixed macOS region selector preference and exclusivity behavior, restored and then reapplied macOS region overlay alignment, aligned the macOS capture sound fallback, normalized clipboard file-drop paths, and cleaned up notification timeout processes.
- XerahS: Fixed unique file path suffix overflow, normalized indexer extension filters, corrected indexer negative-depth traversal, and hardened Sway Wayland rectangle parsing to improve file handling, indexing, and Linux window-query reliability.
