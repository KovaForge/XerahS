## Summary

2026-04-29 was a major platform and release-readiness day in XerahS. Early work tightened headless-editor, uploader, plugin-packaging, hotkey, Imgur, and thumbnail-grid behavior, and the rest of the day shifted heavily into iOS App Store preparation, Android upload-feature parity, Pixelfox registry publishing, and a broad pass on macOS capture settings plus overlay-region alignment.

All verified same-day activity came from the main XerahS repository. `ShareX.ImageEditor` and the available local `XerahS.Editor` checkout had no matching author-dated commits for this UTC+8 day.

## Features

- XerahS: Published the Pixelfox destination-plugin registry package and refreshed the destination plugin index so the plugin metadata in the repo matches the new registry flow.
- XerahS: Added iOS App Store submission scaffolding, including submission docs, export options, privacy manifests, export-compliance metadata, updated identifiers, automatic signing attributes, and a full screenshot set for iPhone and iPad submission assets.
- XerahS: Added Android Play Store submission guidance, API 35 targeting, backup/data-extraction rules, iOS-style S3 endpoint options, SXCU custom uploader support, and share-flow upload-result copying so the Android app moves closer to feature parity with iOS.
- XerahS: Added a new macOS capture-sound setting and region-selector preference plumbing so macOS capture behavior can be configured more explicitly across interactive tools and task settings.

## Fixes

- XerahS: Hardened MCP test adapter asset metadata and fixed the headless-editor unavailable result so MCP and headless automation paths now report more predictable contracts and test against repo build-property drift.
- XerahS: Fixed uploader fallback after a primary failure so later upload targets can still run instead of stopping the overall job too early.
- XerahS: Fixed Nextcloud server URL normalization, FTP host normalization, and Imgur client ID normalization, reducing uploader configuration fragility across multiple providers.
- XerahS: Fixed plugin package install-root creation so plugin extraction and validation have a reliable destination path even on first install.
- XerahS: Fixed workflow hotkey retry after stale failed identifiers so repeated launches recover from outdated failure bookkeeping instead of staying blocked.
- XerahS: Fixed video thumbnail grid column validation so invalid grid input is rejected before thumbnail rendering starts.
- XerahS: Improved the iOS share upload flow and stored uploader secrets in the iOS Keychain, tightening both the extension UX and sensitive-settings handling.
- XerahS: Fixed macOS region-selector preference handling, capture-sound fallback, selector exclusivity, and overlay-region alignment, including a later reapplication and guard explanation after the first overlay alignment fix landed.

## Build and Tooling

- XerahS: Refreshed macOS release assets, including updated `Logo.icns` and the native ScreenCaptureKit bridge packaging inputs, alongside the wider platform-prep work.
- XerahS: Continued the day's fix train with matching tests for MCP, headless editor behavior, uploader fallback, Nextcloud, FTP, hotkeys, Imgur, video thumbnails, and macOS overlay/layout logic.
