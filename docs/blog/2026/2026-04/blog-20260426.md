# XerahS Daily Blog Draft - 2026-04-26

Date: 2026-04-26
Time Zone: UTC+8
Status: Draft

## Summary

2026-04-26 was a broad shipping and platform-integration day across XerahS, mixing a new community plugin installer flow with a long sequence of reliability fixes in uploads, workflow repair, history handling, CLI execution, and indexing. The desktop app also absorbed a same-day ShareX.ImageEditor sync, so editor-side dialog and effect changes moved forward alongside the host application work.

The verified history for this UTC+8 day came from the main XerahS repository plus the checked-out `ShareX.ImageEditor` submodule. `XerahS.Editor` was still not available as a local checkout in this workspace, so no same-day history could be verified there.

## Features

- XerahS: Added the first community plugin registry installer flow, including a dedicated installer dialog, plugin index loading, registry metadata, and documentation for distributing community plugins from a curated index.
- XerahS: Followed the initial registry installer landing with a UX pass that tightened the installer experience and expanded automated coverage for duplicate IDs, API version validation, and invalid registry URLs.
- ShareX.ImageEditor: Synced the editor submodule with the latest upstream ShareX changes and consolidated dialog work, bringing forward editor-side effect, presentation, and hosting updates that XerahS can build on.

## Fixes

- XerahS: Fixed workflow configuration repair for missing task settings and hotkey metadata so broken or partial config entries can be recovered instead of staying unusable.
- XerahS: Fixed clipboard upload attribution, history editor source-file release, and embedded-editor startup behavior so editor-launched and clipboard-driven flows preserve the right uploader context and avoid spurious start-screen behavior.
- XerahS: Fixed upload and path edge cases across Nextcloud relative path dot segments, FTP remote filename sanitization, Imgur album image URL escaping, and cross-platform history filename generation.
- XerahS: Fixed command and background processing issues in the CLI region workflow timeout path, plugin load-context unload tracking, and the indexer folder-count logic, with regression tests added around the affected behavior.
- XerahS: Also carried forward the earlier same-day fixes for macOS service command timeouts, region-capture logical window filtering, FFmpeg recording output handling, blank Nextcloud folder creation, and edited-image upload routing while the release train was still moving.

## Build and Tooling

- XerahS: Published a rapid release sequence from `v0.22.64` through `v0.22.77`, with follow-up version bumps later in the day as more fixes and installer work landed on `develop`.
- XerahS: Added or expanded regression coverage around plugin indexing, workflow-config repair, history launching, FTP sanitization, clipboard upload attribution, and indexer counting so the day's fixes were backed by executable tests instead of ad hoc verification.
- XerahS: Drafted and reviewed KFIP proposals for the community plugin registry and the screen-capture workflow enhancements, which gave the new installer work both implementation backing and written design direction.
- ShareX.ImageEditor: The port/sync work updated editor project metadata and presentation wiring, keeping the embedded editor stack aligned with current upstream code while XerahS continued to integrate it.
