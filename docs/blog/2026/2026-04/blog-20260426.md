## Summary

2026-04-26 was a broad XerahS integration day that started with stabilization work in uploads, OCR, screen recording, region capture, update checks, and history editor launch behavior, then shifted into a larger plugin and editor-sync push. The main desktop repo also pushed out a rapid `v0.22.64` through `v0.22.76` release train before moving on to `v0.22.77` work around the community plugin registry and installer UX.

The verified same-day activity was split between XerahS and ShareX.ImageEditor. ## Features

- XerahS: Added the first community plugin registry installer flow, including registry ingestion, installer dialog updates, a published registry document, and draft `plugins-index.json` support for discoverable plugin metadata.
- XerahS: Expanded the plugin installer UX later in the day so the desktop app can surface the new community registry experience more directly from the UI, with additional view-model and dialog work to support the end-to-end flow.
- XerahS: Added and refined the KFIP0004 proposal work for the community plugin registry and installer, including the proposal rename from KFIP0003 and a draft Pixelfox registry entry to exercise the new schema.
- ShareX.ImageEditor: Synced in a substantial upstream ShareX editor port that introduced start-screen work, dialog and selection refinements, effect-host updates, emoji and toolbar changes, and broader editor surface modernization.

## Fixes

- XerahS: Corrected edited-image uploads so images coming back from the editor are uploaded from the edited output instead of the original preview source.
- XerahS: Fixed FTP and SFTP result URL handling, preserving path separators while still encoding unsafe characters in generated output links.
- XerahS: Reworked SFTP upload execution around `UploadFile()` and safer progress updates to remove the previous slow transfer path and clamp progress reporting more defensively.
- XerahS: Fixed macOS service command timeout handling so the newer process-start path preserves the intended timeout behavior.
- XerahS: Corrected logical window filtering in region capture and fixed FFmpeg recording output path handling, backed by focused regression coverage.
- XerahS: Fixed blank Nextcloud folder creation, OCR language selection normalization, prerelease update-check routing, and history editor source-file launch behavior.
- XerahS: Disabled the start screen in the embedded editor host to keep the integrated editing flow aligned with the surrounding capture workflow.
- ShareX.ImageEditor: The upstream sync and follow-up merge also fixed and refined multiple editor-dialog, effect-parameter, fake-cursor, and startup behaviors inside the standalone image editor codebase.
