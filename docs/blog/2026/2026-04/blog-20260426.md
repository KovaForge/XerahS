## Summary

2026-04-26 was a broad XerahS integration day that started with stabilization work in uploads, OCR, screen recording, region capture, update checks, history editor launch behavior, workflow repair, CLI execution, and indexing, then shifted into a larger plugin and editor-sync push. The main desktop repo also pushed out a rapid `v0.22.64` through `v0.22.77` release train while community plugin registry and installer UX work moved forward.

The verified same-day activity was split between XerahS and the checked-out `ShareX.ImageEditor` submodule. `XerahS.Editor` had no matching commits in the available local checkout for this UTC+8 day, and that checkout still contains unrelated staged deletions, so this post is based only on the history that could be directly verified without mixing in unrelated workspace state.

## Features

- XerahS: Added the first community plugin registry installer flow, including registry ingestion, installer dialog updates, plugin index loading, registry metadata, documentation, and draft `plugins-index.json` support for discoverable plugin metadata.
- XerahS: Expanded the plugin installer UX later in the day so the desktop app can surface the new community registry experience more directly from the UI, with additional view-model/dialog work and automated coverage for duplicate IDs, API version validation, and invalid registry URLs.
- XerahS: Added and refined the KFIP0004 proposal work for the community plugin registry and installer, including the proposal rename from KFIP0003 and a draft Pixelfox registry entry to exercise the new schema.
- ShareX.ImageEditor: Synced in a substantial upstream ShareX editor port and consolidated dialog work, introducing start-screen work, dialog and selection refinements, effect-host updates, emoji and toolbar changes, and broader editor surface modernization.

## Fixes

- XerahS: Fixed workflow configuration repair for missing task settings and hotkey metadata so broken or partial config entries can be recovered instead of staying unusable.
- XerahS: Fixed clipboard upload attribution, history editor source-file release, and embedded-editor startup behavior so editor-launched and clipboard-driven flows preserve the right uploader context and avoid spurious start-screen behavior.
- XerahS: Corrected edited-image uploads so images coming back from the editor are uploaded from the edited output instead of the original preview source.
- XerahS: Fixed FTP and SFTP result URL handling, preserving path separators while still encoding unsafe characters in generated output links.
- XerahS: Reworked SFTP upload execution around `UploadFile()` and safer progress updates to remove the previous slow transfer path and clamp progress reporting more defensively.
- XerahS: Fixed upload and path edge cases across Nextcloud relative path dot segments, FTP remote filename sanitization, Imgur album image URL escaping, and cross-platform history filename generation.
- XerahS: Fixed macOS service command timeout handling so the newer process-start path preserves the intended timeout behavior.
- XerahS: Corrected logical window filtering in region capture and fixed FFmpeg recording output path handling, backed by focused regression coverage.
- XerahS: Fixed blank Nextcloud folder creation, OCR language selection normalization, prerelease update-check routing, CLI region workflow timeout handling, plugin load-context unload tracking, and the indexer folder-count logic.
- ShareX.ImageEditor: The upstream sync and follow-up merge also fixed and refined multiple editor-dialog, effect-parameter, fake-cursor, and startup behaviors inside the standalone image editor codebase.
