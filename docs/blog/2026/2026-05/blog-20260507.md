## Fixes

- XerahS: `PluginLoadContext` now requires matching public key identity for shared plugin dependencies, reducing the risk of binding to the wrong strongly named assembly.
- XerahS: Shared plugin dependency matching is now case-insensitive, fixing resolution failures caused by casing differences between manifests and assembly names.
- XerahS: Invalid fallback assemblies are now ignored instead of poisoning plugin load attempts when fallback probing returns unusable candidates.
- XerahS: DXGI crop rectangles are now scaled correctly before region capture work proceeds, fixing incorrect crop bounds on scaled displays.
- XerahS: The DXGI path no longer advertises native cursor capture support that it cannot actually fulfill, avoiding misleading capability reporting.
- XerahS: Rotated DXGI region captures are now remapped through dedicated rotation logic so the captured output matches the monitor orientation.
