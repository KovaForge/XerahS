Date: 2026-05-19

## Summary

2026-05-19 was a dense XerahS stabilization day focused on workflow correctness across OCR setup, scrolling capture, uploader selection, drag-and-drop ingestion, CLI uploads, and MCP history queries. The only contributor-visible feature addition was a new CLI randomization flag, while most of the day went into closing edge cases that could lose state, misroute uploads, or surface brittle file-handling behavior.

ShareX.ImageEditor and XerahS.Editor had no UTC+8 commits on this date, so this draft is grounded entirely in XerahS repository history for the day.

## Features

- XerahS: Added a `--randomize` flag to the CLI upload command, enabled by default, to append the same style of random alphanumeric suffix used by the desktop app and reduce CDN cache collisions for uploaded files.

## Fixes

- XerahS: Surfaced OCR language refresh failures in both onboarding and the main OCR view model so language download or refresh problems no longer fail silently.
- XerahS: Stopped read-only default-instance checks from mutating uploader configuration by introducing a non-destructive `IsDefaultInstance` path for export payload generation and MCP destination listings.
- XerahS: Fixed a scrolling capture lifetime bug where closing an older capture window could clear the active capture from a newer one, leaving stop actions and orchestration with a null current capture.
- XerahS: Made region capture annotation option persistence awaitable so config saves are completed reliably instead of being left as fire-and-forget work that could be lost.
- XerahS: Normalized upload drag-and-drop file collection handling in `UploadContentWindow`, backed by new regression coverage for the drop pipeline.
- XerahS: Hardened file copy and backup zip replacement behavior by catching expected filesystem exceptions, writing backup archives through a temporary file, and reducing partial-write corruption risk.
- XerahS: Kept auto-uploader fallback selection inside the current uploader category instead of drifting to an unrelated destination type.
- XerahS: Rejected malformed MCP history query parameters instead of letting bad request input leak into runtime handling.

## Build and Tooling

- XerahS: Prevented user-level build props from overriding release guardrails, reinforcing the repository's strict build configuration expectations.
- XerahS: Fixed macOS CLI plugin discovery by preferring the canonical Documents path and bundling the S3 plugin during publish, improving publish-time packaging reliability on macOS.
- XerahS: Most fixes were paired with new regression tests, including coverage for OCR refresh errors, default-instance reads, scrolling capture ownership, annotation persistence, drag-and-drop normalization, file helper recovery paths, uploader fallback selection, and MCP history query validation.
