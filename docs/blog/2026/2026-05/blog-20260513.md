## Summary

May 13 turned into a feature-launch day for capture workflows, with XerahS introducing a new capture command palette backed by fuzzy matching, command discovery, settings integration, and dedicated tests. Alongside that release-sized feature, the team kept tightening onboarding OCR language recovery and regional matching, then quickly polished the new palette by normalizing whitespace handling in its search path. Supporting work also moved the release line into the `0.23.x` series, kept automated releases prerelease by default, and added small contributor-facing tooling and prompt assets.

## Features

- XerahS: Added a capture command palette, including new coordinator, provider, item, fuzzy matcher, view model, window, settings entry points, and tests so capture commands can be searched and launched from a dedicated palette flow.
- XerahS: Wired the new palette into workflow orchestration and application settings, making it a first-class capture interaction instead of an isolated prototype.

- XerahS: Normalized command palette search whitespace immediately after the feature landed so fuzzy matching behaves consistently across padded or irregular queries.
