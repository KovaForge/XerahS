## Summary

May 8 centered on making the Windows DXGI capture path more resilient while also pulling a newer ShareX.ImageEditor snapshot into the XerahS tree. - XerahS: Updated the embedded `ShareX.ImageEditor` snapshot through [`c624b895`](https://github.com/ShareX/XerahS/commit/c624b89555c5179899375b56065d60d73330fa9c), bringing newer upstream editor code into the XerahS port surface.

- XerahS: Added a retry path for full-screen DXGI frame acquisition when Desktop Duplication returns an unusable frame on the first attempt.
