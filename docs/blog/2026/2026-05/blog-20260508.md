## Summary

May 8 combined three threads of work: continued DXGI capture stabilization in XerahS, a large ShareX.ImageEditor upstream sync plus a focused annotation-serialization fix, and a set of contributor workflow updates around the ImageEditor port. The capture work disposed replaced monitor contexts during strategy refreshes, composed cursors directly into DXGI region captures, tightened overlay bounds, and retried full-screen frame acquisition when Desktop Duplication returned a stale frame. ShareX.ImageEditor also landed a substantial same-day port sync with new annotation, toolbar, input, and insert-image work, so this post reflects verified activity from both repositories rather than XerahS alone.

## Features

- XerahS: Added `DisposableContextDictionary` so replaced DXGI monitor contexts can be tracked and disposed consistently when the capture strategy refreshes its monitor state.
- XerahS: Added `DxgiCursorCompositionHelper` so DXGI region captures can explicitly composite the cursor into the captured bitmap rather than depending on unsupported native cursor capture behavior.
- XerahS: DXGI capability reporting now advertises cursor capture support because cursor composition is implemented in the region-capture path.
- XerahS: Synced the latest ShareX.ImageEditor work into the embedded editor stack, including new curved-segment and arrow-style primitives, insert-image dialog plumbing, richer toolbar controls, and a broad refresh of controller and view-model behavior in the Avalonia port.
- ShareX.ImageEditor: The upstream port sync introduced new annotation rendering and editing capabilities, including arrow style handling, font-family selection UI, insert-image workflow support, and broader editor interaction updates that the XerahS port can now build on.
- XerahS: Strengthened the `.ai/skills/port-imageeditor` workflow so future porting passes must carry a manifest, compare behavior against ShareX, pull upstream first, and split deliverables into separate commits.
- XerahS: Added the Android `feature-graphic.png` branding asset needed for store-facing packaging and release preparation.

## Fixes

- XerahS: Disposed replaced DXGI monitor contexts during capture-strategy updates, preventing stale contexts from lingering after monitor refreshes.
- XerahS: Composed cursor pixels into DXGI region captures, fixing missing-cursor output for region shots while aligning capability reporting with the backend's real behavior.
- XerahS: Hardened DXGI cursor overlay handling, then aligned cursor overlay bounds inside the shared composition helper so hotspot and clipping math stay consistent across capture paths.
- XerahS: Added a retry path for full-screen DXGI frame acquisition so output capture can recover when duplication temporarily produces an unusable frame.
- ShareX.ImageEditor: `ImageAnnotation` is now ignored during XANN JSON export, preventing raw bitmap-backed annotations from leaking into serialized annotation data.
- XerahS: Landed the broader `#248` merge on `develop`, carrying forward the latest Linux XDG, plugin diagnostics, and DXGI stabilization work into the main branch history for ongoing validation.

- XerahS: Updated `tests/XerahS.Tests/XerahS.Tests.csproj` so the non-Windows test build includes `DisposableContextDictionary` and `DxgiCursorCompositionHelper` with the rest of the linked Windows capture sources.
