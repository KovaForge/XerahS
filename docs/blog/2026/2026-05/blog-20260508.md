## Summary

May 8 combined three threads of work in XerahS: continuing DXGI capture stabilization, syncing the latest ShareX.ImageEditor work into the Avalonia port, and tightening the repo's ImageEditor porting workflow documentation. The capture work disposed replaced monitor contexts during strategy updates, added a dedicated cursor composition path so region shots can include the cursor, and let the backend truthfully advertise cursor capture support. ShareX.ImageEditor and the available local `_tmp_XerahS.Editor` checkout had no qualifying UTC+8 author-dated commits, so this post is grounded in the XerahS repository history alone.

- XerahS: Added `DisposableContextDictionary` so replaced DXGI monitor contexts can be tracked and disposed consistently when the capture strategy refreshes its monitor state.
- XerahS: Added `DxgiCursorCompositionHelper` so DXGI region captures can explicitly composite the cursor into the captured bitmap rather than depending on unsupported native cursor capture behavior.
- XerahS: DXGI capability reporting now advertises cursor capture support because cursor composition is implemented in the region-capture path.
