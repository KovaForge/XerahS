## Fixes

- XerahS: FFmpeg concat list paths are now escaped correctly, preventing media concatenation flows from breaking on paths that need quoting or escaping.
- XerahS: Embedded editor save now reports primary image-save failures separately from annotation sidecar failures and keeps the document dirty when the main image save fails, so users are not given a false impression that everything persisted correctly.
- XerahS: Annotation sidecar save now re-throws `UnauthorizedAccessException`, preserving the real failure mode instead of swallowing a permissions problem behind a broader save result.
- XerahS: `BackupFileWeekly` now handles an `IOException` time-of-check/time-of-use race, reducing failure risk when backup file state changes between checks and the actual file operation.
- XerahS: `CombineScreenshots` gained explicit `MaxCombinedWidth` and `MaxCombinedHeight` guards plus regression coverage, preventing oversized combined image dimensions from overflowing into invalid bitmap allocation paths.
