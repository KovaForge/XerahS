# XerahS Daily Blog Draft - 2026-01-17

Date: 2026-01-17
Time Zone: UTC+8
Status: Draft

## Summary

Marked a major cross-platform milestone: core platform abstraction hit 100%, Linux gained native X11 and Wayland portal capture paths, and Linux hotkeys/autostart support landed. Documentation around ShareX.Editor reviews and XIP0014 was finalized, and Windows-specific code was moved cleanly behind platform abstractions.

## Features

- Achieved full platform abstraction in the core, moving remaining Windows-specific code into `Platform.Windows` and solidifying the platform boundary.
- Implemented a suite of Linux features: native X11 capture path, a Wayland portal capture strategy, hotkey and input services, and a portal system service that ties XerahS into modern Linux desktops.
- Added Linux hotkeys, autostart, and folder DBus integration so capture and upload workflows feel much closer to first-class citizens on Linux.
- Excluded overlay window handles from capture on Windows, reducing artefacts and making captures cleaner on that platform.

## Fixes

- Aligned Linux portal capture services and improved platform services for both Linux and macOS, ironing out behavioural differences between backends.
- Added platform compatibility guards and CA1416 suppressions to keep Windows-only APIs from leaking into unsupported platforms, reducing runtime surprises.
- Tweaked window positioning and region capture behaviour to use physical coordinates and to respect the new platform abstractions.

## Build and Tooling

- Finalized XIP0014 and multiple ShareX.Editor review documents, including progress reports, new issue listings, and a resume guide, then removed obsolete review progress logs.
- Added conditional console logging for debug builds to provide richer diagnostics without affecting production runs.
- Refactored `XerahS.ScreenCapture` into `XerahS.RegionCapture` and merged multiple docs summarizing phase completion and blocker fixes for ShareX.Editor.

## Notes

- Reaching 100% platform abstraction is a big architectural step; any remaining direct platform calls should be audited, and tests expanded around the abstraction boundary.
- Wayland portal and X11 capture paths introduce new dependencies (portals, DBus, window managers); validating behaviour across GNOME, KDE, and other desktops is crucial.
