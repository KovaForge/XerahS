Date: 2026-01-05
Time Zone: UTC+8
Status: Draft

## Summary

This day marked the separation of the image editor into its own repository and its reintegration into XerahS, while also deepening editor capabilities like cut-out operations, improved rendering, and spotlight behaviour. We also updated SIP0014 docs, cleaned up legacy editor structures, and refined clipboard and capture handling.

## Features

- In XerahS, integrated `ShareX.Editor` with the Avalonia UI, added editor DLLs with core shapes and services, and then restructured the editor into a sibling repo with MVVM layout and updated namespaces (`57bfe327`, `90b58713`, `82175d36`, `a2b19739`, `75bb5a04`).
- In XerahS.Editor, established the editor core with SkiaSharp-based rendering, resizable selection handles, improved Smart Eraser behaviour, and richer annotation rendering (`cb5fe18`, `afd707b`, `f0e3964`, `ff5bd80`, `7eddac9`).
- Added a Cut Out tool with constrained horizontal/vertical cuts and an overlay-based implementation, plus updated overlay colours and strokes to make edits clearer (`fd9c9ca`, `b1d9d72`, `0bb235f`, `f2aec73`).

## Fixes

- Restored Spotlight behaviour to parity with earlier versions and ensured Spotlight overlays fully cover the canvas in the new editor architecture (`ce59c547`, `38170ea`, `c4db6ad`).
- Fixed AXAML namespace references and removed redundant annotations/image effects projects during the editor extraction to reduce confusion and runtime issues (`a0b16b17`, `a2b19739`).

## Build and Tooling

- Updated SIP0014 documentation, including implementation status and guidance on integrating with existing WinForms-based components, and refreshed AGENTS and artifact docs (`611fd611`, `70294fb6`).
- Removed the old `ShareX.Avalonia.code-workspace` and masked in-repo editor artefacts as the editor transitioned to its own repository (`71478b3e`, `86c65887`).
