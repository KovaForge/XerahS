# XerahS Daily Blog Draft - 2026-01-29

Date: 2026-01-29
Time Zone: UTC+8
Status: Draft

## Summary

January 29 was a transformative day for the XerahS user experience, marked by the "Great UI Refresh." The team completed a comprehensive overhaul of nearly every major view in the application, migrating from legacy layouts to a modern, grid-based design system featuring card layouts and enhanced accessibility. Beyond the visual transformation, XerahS shipped its first Avalonia-native auto-update system and introduced a new monitor-cropping strategy for window capture. Concurrently, the `ShareX.ImageEditor` library standardized its tool naming conventions to align with user expectations.

## Features

- XerahS: Implemented a robust **Avalonia UI auto-update system**, enabling the desktop application to check for and apply updates directly through the client interface (`54b95464`).
- XerahS: Added support for **window capture via monitor cropping**, providing a high-performance alternative for capturing application windows on diverse desktop environments (`d73daf5a`).
- XerahS: Expanded the application's configuration surface with a new `ApplicationConfig` property grid and a refreshed **About View** with integrated support links (`c4d20bf5`, `3d302c41`).
- XerahS: Introduced a dedicated **After Upload window** to provide users with immediate access to short links, deletion URLs, and preview thumbnails (`18a3ab7f`).

## Fixes

- XerahS: Standardized preview branding strings and resolved theme alignment issues in the `AfterUploadWindow` and `ColorPickerDialog` (`548edf6a`, `9b752c03`, `eb62f1b8`).
- XerahS: Resolving critical build errors and logging guards in the newly introduced after-upload workflows (`c734a81c`, `6dfe81ee`).

## Build and Tooling

- XerahS: Redesigned over **twenty major views** with standardized typography, icons, and card-based layouts, including:
    - MainWindow, SettingsView, HistoryView, and DestinationSettingsView.
    - ProviderCatalog, PluginInstaller, and HotkeySettings.
    - Recording controls, Toast notifications, and QR Code tools.
- ShareX.ImageEditor: Standardized tool naming across the library:
    - Highlighter renamed to **Highlight**.
    - Pen renamed to **Freehand**.
    - Number renamed to **Step**.
- ShareX.ImageEditor: Refactored the internal windowing logic to use `EditorWindow` as the primary entry point, simplifying the standalone launch flow (`1bbbe317`).
