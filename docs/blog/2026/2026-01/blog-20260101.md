## Summary

On the first day of 2026 we focused heavily on stabilising the new Avalonia-based app, especially the annotation tools, hotkey system, and plugin architecture. We also laid out documentation and coordination scaffolding for future work, including Codex task tracking and plugin development guidance.

## Features

- Added a new plugin destination UX and initial plugin destination implementation, including a dedicated plugin development guide and implementation plan (`ea204fa7`, `23049859`, `a4896b89`, `af14844b`).
- Implemented hotkey persistence using a `HotkeysConfig` model and merged the hotkey persistence feature branch (`49e5e4d4`, `25f4dd63`, `635bf093`).
- Expanded the editor’s capture and annotation capabilities with spotlight annotation, improved selection handles, marching-ants selection borders, and better region capture overlays (`df3ed7a0`, `5b4c3113`, `29626b68`, `64be7b56`, `f552e2f4`).
