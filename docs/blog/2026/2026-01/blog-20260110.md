## Summary

This was a heavy engineering day for XerahS, combining deep Media Foundation/COM interop fixes with a redesigned recording pipeline and a new cross‑platform region capture backend. The editor repos focused on controller refactors, conflict resolution, and setting up a loader project to make the editor easier to run and test in isolation.

## Features

- XerahS: Introduced a cross‑platform region capture backend with Windows implementations, integrated it with existing capture workflows, and updated DXGI API usage to support the new approach (`aa417f6e`, `4ee0c05e`, `21ec1e27`).
- XerahS: Redesigned `TaskSettings` and destination persistence to unify file destination logic and make job‑type‑aware persistence more predictable for recording and capture workflows (`3388271c`, `e7b1603c`, `979dc0d1`, `67a54eef`).
- XerahS: Added weekly backup options and a `backup-settings` CLI command, helping users safeguard their configuration more easily (`0a8e15fe`, `52248053`).
- XerahS: Continued to unify screen recording with the screenshot pipeline, including naming, upload, and path logging improvements, and fixed output orientation issues (`8fc451c9`, `7a6e47be`, `a223bd0f`, `642133d0`, `1e2ef2ca`, `d4409f9f`, `9224b62a`).
- XerahS: Added skill specs, a CLI/bootstrap project for headless workflows, and improved settings to support more flexible automation scenarios (`cba5d603`, `a88d5f93`).
- ShareX.ImageEditor: Refactored editor logic into dedicated controller classes, improved shape selection behavior, and added a loader project that can bring up the editor with a sample image for easier debugging (`d7b01d3`, `633c281`, `24c08dd`, `56b8343`).

## Fixes

- XerahS: Resolved several Media Foundation and Windows Graphics Capture issues by correcting COM interop marshaling, VTable indices, and low‑level encoder interactions, significantly stabilizing recording on Windows (`7374dc0a`, `295104d4`, `b039ec8d`, `fafb4022`, `559c8cb3`, `b6bd5bbe`).
- XerahS: Addressed race conditions and made recording initialization async and platform‑aware to avoid startup glitches in the recording pipeline (`bdeef06e`, `d6773c0f`).
- XerahS: Improved DPI scaling behavior in region capture by using the target monitor’s scaling and restoring the latest DPI fixes, including updates to `.gitignore` and the region capture window implementation (`875fd8b8`, `ea385c9b`, `c79e7a7f`, `97097a3b`, `386aaae7`).
- ShareX.ImageEditor: Resolved merge conflicts in editor controllers, fixed regressions, and removed unused helper methods to keep the refactor stable (`7b764dd`, `d187704`, `fa36f0e`, `d941e4d`).

## Build and Tooling

- XerahS: Added detailed recording‑related logging (including MediaFoundationEncoder logs and length tracking) to make diagnosing recording failures easier (`b6bd5bbe`).
- XerahS: Updated project rules and skills to guide future recording and region capture work (`7534f233`, `cba5d603`).
