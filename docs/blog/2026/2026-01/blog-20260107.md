# XerahS Daily Blog Draft - 2026-01-07

Date: 2026-01-07
Time Zone: UTC+8
Status: Draft

## Summary

We pushed deeply into OS integration today, adding tray icons, Windows toast notifications, and a cross-platform notification service, while also extending Task Settings and hotkey workflows. On macOS, we integrated ScreenCaptureKit and CI, and in the editor we refined the toolbar, settings panel, and crop/cut-out interactions.

## Features

- Introduced a platform notification service with Windows toast support, improved toast configuration, and detailed notification logging, along with stubbing and temporarily disabling unsupported toast UI options in Windows builds (`b3c2df62`, `ad4be91f`, `919f31a8`, `91106fb0`).
- Added tray icon support and OS integration settings, including tray click actions wired through both settings UI and view models (`035e8b48`, `4ddfb599`).
- Refactored general settings into `ApplicationSettingsView` and extended Task Settings with advanced options and workflow cloning/reordering, plus better workflow defaults and reset behaviour (`f4a5dc2c`, `6f24b2c2`, `8b2477d6`, `d3cc4684`, `aab83962`, `7b11ec1c`, `9d84dd34`).
- Added cross-platform window capture improvements including a `SearchWindow` in `IWindowService`, CustomWindow capture UI, and robust window activation/direct window capture on Windows (`0a446d9f`, `c5114410`, `48b1a2c5`, `e35159c9`).
- On macOS, integrated native ScreenCaptureKit and added a macOS CI workflow plus updates to the architecture docs, alongside macOS build workflow tweaks (`dfa4cd48`, `86945ba5`, `ab4106d4`, `b05c74c2`).
- In XerahS.Editor, reworked the editor toolbar layout, added color/width picker dropdowns and tooltips, toggleable settings panel, right-click cancel for crop/cut-out, and refined margins, padding, and styles for a more polished UI (`95587be`, `25ef89d`, `2e01154`, `232ec71`, `d869da8`, `932fd1c`, `61c762f`, `545602b`).

## Fixes

- Ensured hotkey serialisation ignores non-persistent fields like Id and Status, preventing configuration noise and potential incompatibilities (`9d84dd34`).
- Performed general “code cleanup” and layout refinements on both the app and editor UI to reduce technical debt before further feature work (`67f39c68`, `61c762f`, `545602b`).

## Build and Tooling

- Added and tuned macOS CI via `macos-build.yml`, updating it multiple times and aligning it with the new ScreenCaptureKit integration and architecture documentation (`86945ba5`, `ab4106d4`, `b05c74c2`, `dfa4cd48`).
- Continued to refactor debug logging by routing window activation and notification-related logging through `TroubleshootingHelper`, centralising diagnostics for OS integrations (`c178849c`).
