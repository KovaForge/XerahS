Date: 2026-01-31

## Summary

January 31 marked the completion of the major January development goals, most notably the full integration of the **Custom Uploader system**. This rollout includes a comprehensive UI editor, compatibility testing suites, and seamless integration into the destination settings. In addition, critical fixes for high-DPI scaling and multi-monitor coordinate alignment stabilized the annotation layer for professional use. The project celebrated these milestones by reaching the v0.7.0 version mark, while the editor library was formally renamed to `ShareX.ImageEditor`.

## Features

- XerahS: Completed the **Custom Uploader integration** (XIP0024 Phases 1-4), providing users with the ability to define, test, and manage custom destination endpoints directly in the UI (`59628704`, `8020d731`, `9bf8ceb9`).
- XerahS: Added a **dynamic mode indicator** for annotation/region capture to provide real-time feedback on the current interaction state (`a03f4c65`).
- XerahS: Shipped the **RectangleTransparent** workflow, enabling frozen-screen captures with transparent background support for specialized documentation needs (`c92a3d0b`, `9ee7277f`).
- XerahS: Introduced the **green reminder pill** for the Enter key when both annotations and region selections are active, clarifying the double-action requirement for finalization (`38752989`, `6e31414c`).

## Fixes

- XerahS: Resolved longstanding **high-DPI and multi-monitor coordinate issues** that caused misaligned annotations on captures spanning diverse monitor scales (`5d694256`, `61bd0c97`).
- XerahS: Fixed XAML binding resolutions in the `CustomUploaderEditorDialog`, ensuring the new editor works reliably across different host environments (`be634d25`).
- XerahS: Optimized screen capture and bitmap conversion routines to reduce memory pressure and improve the responsiveness of large-region captures (`b42a2463`).

## Build and Tooling

- XerahS: Promoted the application version first to v0.6.3 and then to the landmark **v0.7.0** release (`593d7e3c`, `5734aa03`).
- ShareX.ImageEditor: Formally renamed the repository and project from ShareX.Editor to **ShareX.ImageEditor**, aligning with the official library naming convention (`a1904b87`).
- XerahS: Added unreferenced properties audit scripts to further reduce application footprint and identify dead code in the view layer (`2cfc9ded`).
