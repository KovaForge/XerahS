# XerahS Daily Blog Draft - 2026-01-03

Date: 2026-01-03
Time Zone: UTC+8
Status: Draft

## Summary

This was a major day for macOS and plugin infrastructure: we landed the macOS platform MVP, including clipboard, hotkeys, and screen data, alongside a comprehensive plugin packaging and exporter flow. We also added integration settings, a workflow wizard, and multiple docs updates to support macOS publishing and permissions.

## Features

- Implemented the macOS platform MVP with Avalonia screen data, clipboard PNG and file list support, frontmost window info, and platform services (`b6277d8f`, `c01cd68a`, `d17e1b98`, `97957d78`, `acba9d5c`).
- Added macOS hotkey support using SharpHook, including accessibility checks and error handling, to bring global hotkeys closer to parity with other platforms (`c52ca388`, `ca05d4b5`, `a96a407c`).
- Built a full plugin packaging pipeline: plugin packaging and installer, hardened package install, a plugin exporter CLI, `.sxadp` file association UI, and Amazon S3 plugin packages (`f81c6567`, `433788c1`, `cead71a5`, `020ddde3`, `df9bbd1d`, `f05e5024`).
- Introduced integration and import features such as an Integration settings tab, `.sxadp` association controls, and ShareX `UploadersConfig` import functionality (`df9bbd1d`, `5cebbb5f`, `b622a726`, `7c6efe25`).
- Added a workflow wizard UI and view models, enabling editing workflows in a wizard experience and refining hotkey-related UX (`1a8f17b6`, `21afe90a`, `4c034031`, `ed864c77`).

## Fixes

- Hardened plugin package install and ensured clipboard operations run on STA threads to avoid subtle runtime issues (`433788c1`, `3af77326`).
- Fixed `SharpHook` start failures for macOS hotkeys to make global hotkey registration more resilient (`a96a407c`).

## Build and Tooling

- Added and refreshed extensive macOS documentation: platform implementation doc (SIP0013), publish and entitlement checklist, hotkey status and validation steps, and clarity on macOS hotkey permissions (`0fb4b4ad`, `063fcc60`, `0656da60`, `4a7ef55e`, `9b3ed998`, `6302db33`).
- Updated README and license information to reflect the new platform scope and naming (`6dd9f1f1`, `69c8ebb4`, `93c0f733`).
