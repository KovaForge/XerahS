## Summary

January 30 was a milestone day for platform reach and deployment efficiency. XerahS successfully implemented native macOS build integration and application bundle packaging, while also automating multi-architecture Windows builds. Concurrently, the team launched support for user-installed plugins and reached a major development goal by enabling the new Annotation Toolbar within the Region Capture Overlay. In the background, the `ShareX.ImageEditor` library refined its save logic and finalized its configuration refactores.

## Features

- XerahS: Achieved **macOS platform parity** with the implementation of native build integration and single-file app bundle (.app) packaging (`c2b882c4`).
- XerahS: Introduced formal support for **user-installed plugins**, including logic to bundle and package plugins specifically for macOS environments (`e7875367`, `e33685f8`).
- XerahS: Integrated the **Annotation Toolbar into the Region Capture Overlay** (XIP-0023), allowing users to draw and label captures before finalizing the region selection (`05dcaf37`, `cb812516`).

## Fixes

- ShareX.ImageEditor: Refactored the core **save and pin logic** within editor view models to ensure more predictable data handling during file interactions (`fb027d71`).
- ShareX.ImageEditor: Prevented potential infinite feedback loops during state synchronization between the core and the `MainViewModel` (`0e381bc6`).

## Build and Tooling
