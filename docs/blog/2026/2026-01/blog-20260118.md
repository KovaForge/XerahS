# XerahS Daily Blog Draft - 2026-01-18

Date: 2026-01-18
Time Zone: UTC+8
Status: Draft

## Summary

Region capture and image workflows got significantly richer: mouse cursor overlays, in-pipeline image effects, preset import/save flows, and a more discoverable upload experience all landed. At the same time, the team burned down high-priority Platform.Windows resource leaks and race conditions, modernized the README, and cleaned up hundreds of license headers.

## Features

- Extended the capture workflow to support mouse cursor capture and overlay, along with applying image effects directly in the capture pipeline.
- Added image effects preset import plus save/load support, enabling reusable effect configurations that can be shared and reused across sessions.
- Reordered the annotation pipeline so that annotation happens before image saving, ensuring user edits are always applied to the final output.
- Introduced a file upload dialog for `FileUpload` jobs and surfaced upload progress in the window title, making long-running uploads more transparent and approachable.

## Fixes

- Fixed multiple BLOCKER and HIGH-priority Platform.Windows issues, including resource leaks and race conditions that could cause crashes or hangs under load.
- Improved cursor hiding during DXGI screen capture and reworked the image editor so it correctly returns the edited image, preventing inconsistent downstream behaviour.
- Resolved 562 non-compliant GPL v3 license headers across the codebase, cleaning up legal and stylistic debt in one sweep.

## Build and Tooling

- Modernized the README with up-to-date XerahS features and workflows, and updated the CHANGELOG with unreleased features and fixes so documentation better matches reality.
- Tweaked default workflow hotkey assignments and FAQ entries around workflow configuration and pronunciation, reducing friction for new users.
