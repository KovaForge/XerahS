# XerahS Daily Blog Draft - 2026-01-06

Date: 2026-01-06
Time Zone: UTC+8
Status: Draft

## Summary

Today was dominated by SIP0016 “Modern Capture” work, delivering a cross-platform capture stack (Windows DXGI, Linux CLI, macOS wrapper) plus performance and logging improvements. We also evolved workflows and history management in XerahS, and in XerahS.Editor we improved annotation UX (speech balloons, selection logic) and editor toolbar styling.

## Features

- Implemented SIP0016 Stage 1–3 modern capture: DXGI-based capture on Windows, CLI-based capture on Linux, and a macOS capture CLI wrapper, with unified debug logging and capture service selection logic (`1440efc9`, `18fd7063`, `b637a743`, `9182ff7a`).
- Added a “Use Modern Capture” toggle in advanced settings, plus additional performance logging for region capture and startup logging for better diagnostics (`2cbecd13`, `25f544d5`, `df5764e4`, `c94ce299`).
- Refactored the hotkey editor into a workflow editor, added workflow descriptions and dynamic window titles, and removed the older Workflow Wizard in favour of a more integrated Task Settings UI, including live image effect previews and an image effects editor (`fd395c3e`, `7d2b6eea`, `054c9a90`, `76ca3c8b`, `f46995fc`).
- Improved data durability and access in history and settings by switching history storage from XML to SQLite, adding automatic backups, log and settings folder commands, daily log rotation, and personal-folder-based paths (`22b6cf5a`, `0f20d766`, `293886cf`, `6b61f4be`, `275a94a6`, `435dc46f`, `1c8014c3`).
- In XerahS.Editor, added interactive speech balloon annotations with in-place text editing, better tail positioning, and automatic entry into text-edit mode (`7cb0673`, `6bfb5fc`, `cc80748`, `5da5ad8`, `8343f60`).

## Fixes

- Fixed multi-monitor blank capture issues and null-reference crashes in modern capture flows, as well as improving DXGI adapter handling and startup wiring for capture selection (`52ae45ec`, `df9bd339`, `25f544d5`, `c94ce299`).
- Corrected selection logic and spotlight overlay coverage in the editor so hit testing and overlays behave reliably (`7679e7f`, `f8aa311`).
- Addressed speech balloon initialisation quirks and selection issues in the editor to make annotation editing smoother (`cc80748`, `6bfb5fc`).

## Build and Tooling

- Documented modern capture architecture and merged Linux support changes, including the SIP0016 architecture doc and Linux feature branch integration (`fea10715`, `5d482449`, `402616ff`).
- Added a “Open Logs Folder” debug command and related debug helpers to streamline performance investigation and capture troubleshooting (`7c42a835`, `9182ff7a`).
