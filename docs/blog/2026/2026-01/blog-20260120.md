Date: 2026-01-20

## Summary

Workflow ergonomics and macOS/Linux platform polish were the themes today. Watch-folder workflows, index-folder tooling, and ScreenCaptureKit integration advanced, while terminology and documentation were cleaned up so contributors and users have a clearer mental model of workflows versus hotkeys.

## Features

- Introduced an index folder tool and companion workflow so users can generate and manage index views directly from XerahS.
- Built out watch-folder capabilities, including per-entry enablement, per-folder workflow assignments, and a default `FileUpload` workflow for watch folders.
- Added native macOS ScreenCaptureKit video recording support, extending the macOS capture pipeline with first-class recording.
- Renamed `HotkeyType` to `WorkflowType` across the codebase to better represent the abstraction and avoid conflating hotkeys with underlying workflows.

## Fixes

- Tightened the conceptual model around workflows vs hotkeys, reducing opportunities for configuration errors and confusion in both code and UI.
- Refined ScreenCaptureKit integration and workflow wiring so that macOS capture behaves predictably with the new workflow system.

## Build and Tooling

- Updated `AGENTS.md` with refined guidance for agents and automation working in the repo, improving contributor ergonomics.
- Renamed legacy ShareX.Avalonia references in documentation to XerahS, aligning branding and reducing cross-project confusion.
- Merged documentation cleanup and workflow-related changes into `develop` via a dedicated pull request.
