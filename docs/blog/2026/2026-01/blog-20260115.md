# XerahS Daily Blog Draft - 2026-01-15

Date: 2026-01-15
Time Zone: UTC+8
Status: Draft

## Summary

XerahS completed the large-scale rename from `ShareX.Avalonia` to the new `XerahS` naming across core, platform, and UI projects, while also introducing the first automated RegionCapture verification CLI. Across the editor repos, we refactored image effects into a clearer structure and started wiring the standalone editor to support upload, copy, and save-as flows. The day also delivered important DPI and coordinate fixes for multi-monitor and Linux X11 capture.

## Features

- XerahS: Introduced an automated `RegionCapture` verification CLI command and surfaced workflow IDs in the editor to make debugging and automation easier.
- XerahS: Completed the migration from `ShareX.Avalonia.*` folders and solution names to the `XerahS.*` branding, covering core, platform-specific, services, UI, and tooling projects.
- ShareX.ImageEditor: Added new image effect dialogs and filter implementations, laying groundwork for a more modular and extensible effects pipeline.
- XerahS.Editor: Hooked up handlers for copy, save-as, and upload requests from the editor so captures can be more easily exported and uploaded via XerahS workflows.

## Fixes

- XerahS: Fixed window boundary click capture, negative coordinate handling, and multi-monitor coordinate transformation bugs in screen and region capture.
- XerahS: Implemented per-monitor DPI support for Linux X11 and removed legacy DPI code to rely exclusively on the modern backend.
- XerahS: Corrected region capture window boundary detection and auto-confirm behavior, and improved clipboard alpha conversion for image data.
- ShareX.ImageEditor / XerahS.Editor: Improved blur behavior to avoid edge transparency and ensured base effect annotations are treated as vector annotations for consistent rendering.

## Build and Tooling

- XerahS: Renamed the main solution file to `XerahS.sln` and moved build and script files into new directories to better match the updated project layout.
- ShareX.ImageEditor / XerahS.Editor: Refactored `ImageHelpers`-based effects into dedicated `Manipulations*`, `Adjustments*`, and `Filters*` effect classes, splitting the large adjustment file into individual effect files for maintainability.
