# XerahS Daily Blog Draft - 2026-01-12

Date: 2026-01-12
Time Zone: UTC+8
Status: Draft

## Summary

XerahS focused on installer, CLI, and plugin ergonomics while documenting a new SIP around hybrid rendering. The editor repos shipped hybrid SkiaSharp/Avalonia rendering, richer undo/redo for image‑level operations, a ZoomPicker, and a substantial expansion of image effects and adjustment dialogs.

## Features

- XerahS: Created and iterated the Inno Setup script (`XerahS-setup.iss`), including new bash commands and later updates, to formalize how the app is packaged for Windows (`a7f28581`, `21a7bd3e`, `882705fe`).
- XerahS: Migrated the CLI to `System.CommandLine` 2.0.1 stable and added an “Open Plugins Folder” button plus refactored plugin folder path management, making both automation and plugin workflows easier (`8d0e27ff`, `b9741fa3`, `eba42e9e`).
- XerahS: Introduced Avalonia diagnostics support and documented a new SIP0018 for hybrid rendering, with multiple passes over the design document (`bc7bb0a6`, `9b9ff328`, `2a20dfa3`, `2d67d767`, `d91e7616`, `88403b6a`).
- ShareX.ImageEditor: Implemented hybrid SkiaSharp/Avalonia rendering in the editor and added a cut‑out annotation tool with undo/redo support, plus image‑level undo/redo for crop and cutout operations (`e488663`, `7efad5d`, `816c00b`).
- ShareX.ImageEditor: Added a ZoomPicker dropdown with discrete levels and refined zoom controls, along with UI styling updates to EditorView and dialogs for a more polished editor surface (`fa6d58f`, `ab8da9c`, `5c89cb7`, `37b5f01`, `acc1fae`, `e449cae`).
- ShareX.ImageEditor: Added an edit menu dropdown and a comprehensive set of image effects/effects dialogs (Grayscale, Replace Color, Colorize, Selective Color, adjustments), and wired up manipulation helpers to drive them (`2a9beee`, `13bfbc7`, `fc2cdca`, `967024a`, `c35314a`, `ef5b303`).
- ShareX.ImageEditor: Improved annotation history integration and annotation restore behavior so undo/redo state stays in sync with what’s visible in the editor (`71c5e51`, `97e0a83`, `d332299`).

## Fixes

- ShareX.ImageEditor: Removed the legacy `ImageEffects` module and related classes to avoid duplication and keep the new effect system maintainable (`befdd24`).

## Build and Tooling

- XerahS: Enabled Avalonia diagnostics and updated SIP0018 hybrid rendering docs, giving developers both runtime inspection tools and a clear design reference for hybrid rendering trade‑offs (`bc7bb0a6`, `9b9ff328`, `2a20dfa3`, `2d67d767`, `d91e7616`, `88403b6a`).
- ShareX.ImageEditor: Enabled developer tools, adjusted the main window to start maximized, and refined design area sizing and popup styles for a better development and testing experience (`34a5d5b`, `c657489`, `5c89cb7`).
