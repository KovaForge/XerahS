# XerahS Daily Blog Draft - 2026-01-25

Date: 2026-01-25
Time Zone: UTC+8
Status: Draft

## Summary

January 25 saw the arrival of the highly requested "Pin-to-Screen" feature in the `ShareX.ImageEditor` library, allowing users to keep captured regions floating on top of their workspace. The project also underwent a significant cleanup phase, with the removal of legacy verification projects and standardizing build properties. On the XerahS side, the v0.5.0 feature set was expanded to include history recording for uploads that result only in a URL, closing a long-standing gap in the application's activity tracking.

## Features

- XerahS: Implemented history recording for URL-only uploads, ensuring that all successful tasks are logged in the main history view regardless of whether a file was saved locally (`ff8e75bf`).
- ShareX.ImageEditor: Introduced the **Pin-to-Screen** capability, providing a dedicated floating window path for captured content and updating the editor's bottom bar UI to support this new workflow (`05d141aa`).
- ShareX.ImageEditor: Enabled shadow effects by default for all new annotations to improve contrast and visual separation (`7908db0c`).

## Fixes

- ShareX.ImageEditor: Improved annotation removal logic to correctly update the `HasAnnotations` state, ensuring proper UI feedback for undo operations (`90a0ef2d`).
- ShareX.ImageEditor: Standardized button sizes, tooltips, and reordered the upload and pin buttons in the editor toolbar for better ergonomics (`703bb962`, `73873e4e`).
- ShareX.ImageEditor: Added conditional tool options separator logic to prevent empty toolbar spaces (`b50568b3`).

## Build and Tooling

- ShareX.ImageEditor: Conducted a general repository cleanup by removing the `ShareX.Editor.Verification` project and the redundant `Directory.Build.props` file (`98abbe24`, `ec349f20`).
- ShareX.ImageEditor: Updated license information and project copyright years across the library core (`be015896`, `a59e3c4c`, `7aeed79a`).
