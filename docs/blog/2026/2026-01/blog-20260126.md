## Summary

January 26 focused on the fine-grained visual and interactive details of the `ShareX.ImageEditor` tool suite. The day brought substantial improvements to speech balloon and text annotation stability, specifically enabling in-place editing and resolving contrast and clipping issues. The editor's filter effects, including blur and spotlight, were hardened to handle out-of-bounds regions, while the entire application ecosystem was standardized on Avalonia 11.3.9 to ensure cross-platform build consistency.

## Features

- ShareX.ImageEditor: Enabled **in-place editing** for text annotations and speech balloons, providing a much more direct and intuitive content modification experience (`91b95ea8`, `e775c370`).
- ShareX.ImageEditor: Significantly upgraded speech balloon capabilities with support for font size selection, text wrapping, and improved internal padding logic (`001391e7`, `dbbc352c`, `66a2ce9c`).
- ShareX.ImageEditor: Added active state styling to toolbar picker dropdowns to provide clearer visual feedback during selection (`6454b905`).

## Fixes

- XerahS / ShareX.ImageEditor: Standardized all Avalonia packages and build configurations to version 11.3.9, resolving version mismatches that were affecting cross-repo stability (`63861be6`, `430ce808`).
- ShareX.ImageEditor: Hardened image filter effects—specifically blur, spotlight, and magnify—to correctly handle image edges and out-of-bounds selection regions (`28927d6b`, `b8594c64`, `cbc59885`, `9512e64b`).
- ShareX.ImageEditor: Refined text annotation behavior by removing artificial minimum widths and improving click-to-edit selection triggers (`164ec5a4`).
- ShareX.ImageEditor: Resolved contrast issues in text editors by syncing the `CaretBrush` with the foreground color (`205b4c4d`, `200ea0b0`).

## Build and Tooling

- ShareX.ImageEditor: Added minimum shape size validation to all annotation tools to prevent accidentally creating invisible sub-pixel annotations (`72bf393f`).
