# XerahS Daily Blog Draft - 2026-03-20

Date: 2026-03-20
Time Zone: UTC+8
Status: Draft

## Summary

March 20 was dominated by two parallel tracks that eventually converged at the end of the day. On one front, the annotation toolbar underwent heavy surgery: the toolbar was extracted from the RegionCapture overlay, refactored to be shared with ShareX.ImageEditor, and then put back together with a string of incremental fixes that restored button shapes, margins, tool-options rows, and action placement to their expected layout. On the other front, the app-level theme system absorbed ShareX.ImageEditor's new OS-aware accent and system-theme support so both surfaces now follow the same adaptive color contract. The day closed with two notable additions: the creative image effects package was wired into both repositories, and an autoresearch runner bundle was committed to track and execute speculative filter research missions.

## Features

- XerahS: The inline workflow-type dropdown was removed from `HotkeySelectionControl`; workflow type changes now route through the Workflow Editor dialog, cleaning up an ad-hoc shortcut that bypassed the intended editing flow.
- XerahS: The annotation toolbar was refactored to be a shared Avalonia control owned by ShareX.ImageEditor and consumed by both the RegionCapture overlay and the standalone Image Editor. This means toolbar styling and behavior is now maintained in one place across both surfaces.
- XerahS: A new autoresearch runner bundle (`.autoresearch/autoresearch.ps1`) was committed, bundling a PowerShell-driven mission system for exploring speculative filter work (heat-haze refraction, luminance contour lines, nebula/starfield, paper stencil mask, riso print, and a general bug-fix runner).
- XerahS: Creative image effects were added to the XerahS build (`aa62a121`) by pulling in the latest ShareX.ImageEditor submodule revision that introduced those effects, and new autoresearch mission files were created to guide their development.
- ShareX.ImageEditor: OS-aware accent and system-theme support was introduced into the editor (`5a74b4b`, `d2e2b2d`), making the editor's surface colors respond to the host OS accent and light/dark mode without XerahS having to push those values in manually.
- ShareX.ImageEditor: A Blood Splash procedural effect with its own dialog was added (`38ace34`), continuing the expansion of the creative effects catalog.
- ShareX.ImageEditor: The annotation toolbar button styles were centralized and unified (`140fcfe`), establishing a shared style baseline that aligns the RegionCapture and Image Editor toolbars.

## Fixes

- XerahS: Multiple annotation toolbar layout regressions introduced during the sharing refactor were corrected in rapid succession: the right-side action strip (`613ad215`), the shared-toolbar legacy layout alignment (`a5a22032`), the centered split annotation-options row (`b6b0e72f`), square button shapes (`0ca7ad9d`), and fixed-width button sizing (`2a6e64f3`) were each restored individually.
- XerahS: Annotation toolbar tool-options (the per-tool settings row) were broken during the refactor and were fully restored (`7e0ac98b`) alongside a major ViewModel expansion that moved per-tool option state management into `RegionCaptureAnnotationViewModel` with new tests.
- XerahS: Scrolling capture stitching was corrected (`4c4b7c73`): `ScrollingCaptureManager` was refactored with 282 new tests covering scroll, stitch, deduplication, and edge-overlap scenarios, fixing incorrect frame-alignment logic that was producing malformed panoramic screenshots.
- XerahS: The app now uses the native Windows "Send To" shortcut via the Shell integration service rather than a constructed path, fixing cases where the shortcut could not be resolved on non-standard Windows installs (`56a769a6`).
- ShareX.ImageEditor: Several annotation toolbar layout fixes were backported to the ImageEditor side in parallel with the XerahS fixes: right-aligned actions (`fb72967`), legacy layout match (`7cc7fcc`), square buttons (`0af94ad`), centered split options row (`ebbde38`), and fixed-width buttons (`108f0ed`) were all corrected to stay in sync.

## Build and Tooling

- XerahS: Theme service in `XerahS.UI` was expanded (`dd9d2f05`) to use ShareX.ImageEditor's system-theme APIs, letting the main app respond to OS-level light/dark/accent changes without carrying its own accent-detection logic.
- XerahS: `AnnotationToolbar.axaml` and `AnnotationToolbar.cs` were deleted from XerahS.RegionCapture and the overlay window was updated to consume the toolbar from ShareX.ImageEditor directly, removing roughly 550 lines of duplicated control code (`151cec4c`).
- XerahS: `OverlayWindow.axaml.cs` was expanded with override and initialization support for the shared toolbar, and `RegionCaptureAnnotationViewModel` was updated to drive the now-external toolbar control through a common interface.
- XerahS: `RegionCaptureAnnotationViewModelTests` was added alongside the VM expansion, adding coverage for tool options, annotation mode transitions, and toolbar interaction paths.
- XerahS: A release-checklist documentation suite was committed (`2268b33f`) covering production readiness tracking for views, workflows, and controls.
- XerahS: Agent workflow rules updated to mandate sub-agent delegation for large or parallelizable tasks (`74ad52f0`), and `MULTI_AGENT_COORDINATION.md` was refreshed accordingly (`ce04da8b`).
- ShareX.ImageEditor: Package versions were centralized into a shared props file (`311b2ba`), eliminating scattered `PackageReference` version literals across projects.
- ShareX.ImageEditor: Sidebar header style, Background label, separator color, and right-panel text styles were added as shared resources (`a6bdb4b`, `68c1638`), bringing more of the editor's layout surfaces onto named tokens.
- ShareX.ImageEditor: The annotation toolbar and effect visual bridge were shared with XerahS (`adcdc86`), establishing the handoff contract that the XerahS side then consumed.

## Notes

- The annotation toolbar sharing work involved several rapid fix cycles due to layout regressions introduced by the refactor; the final state is stable but the incremental churn points to a need for visual regression tests covering the toolbar layout.
- `RegionCaptureAnnotationViewModel` grew significantly during the tool-options restoration, receiving the full option-state model that was previously implicit in the XAML. This warrants a follow-up review to ensure the model is maintainable as more tools are added.
- Scrolling capture stitching was fully test-covered in this pass (282 new tests), which is a positive sign for stability of that feature path.
- The autoresearch runner is currently a speculative research tool and not tied to CI; the missions it tracks (heat-haze, nebula, riso, etc.) are exploratory filter ideas that have not shipped yet.
