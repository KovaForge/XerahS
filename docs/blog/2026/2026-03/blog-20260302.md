# XerahS Daily Blog Draft - 2026-03-02

Date: 2026-03-02
Time Zone: UTC+8
Status: Draft

## Summary

Focused on Linux global shortcuts and portal behavior, turning the Wayland GlobalShortcuts portal into a first-class citizen while tightening packaging, diagnostics, and regression coverage around rotated-monitor capture issues.

## Features

- Implemented a native Wayland GlobalShortcuts portal integration so Linux hotkeys can be configured and used via the desktop’s standard portal instead of bespoke hacks.

## Fixes

- Fixed several Linux hotkey and portal edge cases, including retrying portal binding after windows open, debouncing bindings to avoid multiple GNOME dialogs, and aligning the Wayland `app_id` with the desktop file.
- Hardened Linux packaging by symlinking `/usr/bin/xerahs`, fixing `StartupWMClass`, and adding diagnostics around `BindShortcuts` so portal misconfigurations are easier to spot.
- Added regression tests to guard against rotated-monitor black-screen issues and improved shutdown behavior by unsetting `SESSION_MANAGER` / `SM_CLIENT_ID` to avoid XSMP shutdown hangs.

## Build and Tooling

- Bumped versions to v0.19.1 and v0.19.2 with accompanying Directory.Build and CHANGELOG updates, including parallelized Linux plugin publish flows.
- Updated ImageEditor and Directory.Build props so the editor and main app stay aligned with the same build configuration as portal/hotkey work evolves.
- Captured diagnostic findings and packaging notes in XIP0044 documentation to make future Linux portal debugging more repeatable.
