# XerahS Daily Blog Draft - 2026-03-13

Date: 2026-03-13
Time Zone: UTC+8
Status: Draft

## Summary

March 13 started with user-facing work in History, editor theming, and frontend setup, then expanded into a broader UI platform cleanup that removed `FluentAvalonia` from XerahS and standardized shared surfaces ahead of `v0.20.2`. The day also folded in ShareX.ImageEditor cursor and typography improvements so XerahS and the editor stack can share one visual contract instead of drifting apart. Release automation and packaging were tightened in parallel so the Chocolatey flow could complete cleanly after the UI refactor.

## Features

- Added History image combine actions in XerahS so selected entries can be grouped into new downstream image-combining workflows from the History surface.
- Promoted ShareX.ImageEditor to the shared source of truth for typography and semantic icon aliases, then adopted that contract inside XerahS so shell views, toolbars, and routed pages speak the same visual language.
- Replaced the shell navigation primitives with XerahS-owned navigation nodes and introduced shared page and window surface foundations, giving later dialogs and routed views a common base to build on.

## Fixes

- Restored History thumbnail rendering by reconnecting the History views to the loaded item collection instead of leaving the UI pointed at stale bindings.
- Improved ShareX.ImageEditor cursor behavior during drawing, selection, zoom, and panning by loading the custom crosshair asset, adding hand cursors, and keeping both canvases synchronized during interaction.
- Applied shared content hosts, secondary backgrounds, card surfaces, and derived-view surfaces across XerahS so the Avalonia primitive migration does not leave dialogs or routed pages with mismatched backgrounds.
- Hid the duplicate inline custom uploader name in the settings flow so uploader configuration no longer repeats the same label in two places.

## Build and Tooling

- Upgraded `ShareX.VideoEditor` to the Vite 8 toolchain, refreshed the frontend lockfile, and documented the newer Node.js requirement in both contributor-facing setup guides.
- Removed the `FluentAvalonia` package from XerahS, added compatibility resources around official Avalonia primitives, and tracked the migration with the new `XIP0050` proposal.
- Released `v0.20.2` and fixed the Chocolatey synchronization script so CRLF installs and package output paths no longer break the packaging hand-off.
