# XerahS Daily Blog Draft - 2026-03-03

Date: 2026-03-03
Time Zone: UTC+8
Status: Draft

## Summary

Expanded XerahS’s import and scrolling capture story while continuing to invest in Linux tray integration and ImageEditor performance, with a particular focus on making ShareX config imports and long-page captures feel reliable.

## Features

- Added a BuiltinInstanceMigrator to automatically migrate S3, FTP, Pastebin, Imgur and other builtin instances when importing classic ShareX configs, reducing manual setup for existing users.
- Extended scrolling capture with a MouseWheelMessage scroll method, making long-page captures more robust and less sensitive to per-app behavior.

## Fixes

- Fixed multiple issues in the ShareX config import pipeline, including auto-creating instances, cleaning up reload behavior, and de-duplicating entries in `AddCustomUploader`.
- Improved scrolling capture reliability by restoring cursor position after mouse-wheel ticks and ensuring re-clicking an already-active Upload/Capture nav item re-triggers its action.
- Validated URLs before `OpenURL` `Process.Start` and enforced cleaner plugin path selection defaults via `PathsManager`.
- Continued Linux quality work by adding system tray support for GNOME/Wayland via SNI protocol and tightening URL and portal-related docs for known issues.

## Build and Tooling

- Centralized plugin path selection in `PathsManager`, making plugin discovery more predictable across platforms.
- Enforced a standard release-notes block in CI so future releases carry consistent, machine-checked changelogs.
- Advanced ImageEditor performance and stability via “easy wins” (Random.Shared, category overrides, gamma LUT cache) and synced the submodule and related XIP0042/XIP0044 documentation.
