# XerahS Daily Blog Draft - 2026-03-29

Date: 2026-03-29
Time Zone: UTC+8
Status: Draft

## Summary

March 29 UTC+8 was dominated by two converging tracks: the IEIP0006 wallpaper prewarm refactor landing in both XerahS and ShareX.ImageEditor, and a significant ShareX.ImageEditor UI-polish push covering the standalone editor's toolbar, file menu, key bindings, and close-confirmation behaviour. XerahS also hardened its region capture integration by disabling the `ImageEditorMode` flag in the annotation toolbar adapter, preventing the extra File button from surfacing in the overlay editor context, and patched a reentry bug in the editor confirmation overlay. The IEIP0006 proposal itself grew in scope through iterative documentation commits that added the `ShareX.ImageEditor.Loader` host module and outlined alternative approaches using native JXL libraries.

## Features

- XerahS / ShareX.ImageEditor: IEIP0006 — moving wallpaper prewarm into the editor host layer — landed as a concrete refactor in both repositories on the same evening. XerahS implemented the proposal by relocating the wallpaper prewarm and conversion logic from the Linux-specific `LinuxDesktopWallpaperProvider` into the `ShareX.ImageEditor` library and wiring the shared services through the editor host. ShareX.ImageEditor received the complementary `[Refactor] Move wallpaper prewarm into editor` commit in parallel. This change makes the prewarm behaviour platform-neutral and removes the duplication between desktop and future hosts (`b75580f0`, `218ee51d`).
- ShareX.ImageEditor: The standalone editor's file-menu surface expanded. A flyout-based File menu button replaced the earlier placeholder, keyboard shortcuts `N` and `O` were wired to New and Open, an Escape binding was added to exit the standalone editor, and the toolbar visibility bindings were adjusted so the bottom bar shows only in the appropriate host mode (`614230cd`, `6a4ac8d2`, `10e1c10c`, `2385d89a`).
- ShareX.ImageEditor: Image format support was extended and tidied. AVIF was added as a supported save and import format, and the BMP save option was dropped since it is rarely useful and clutters the format picker (`b45fc08c`).

## Fixes

- XerahS: `ImageEditorMode` was disabled in the region capture annotation toolbar adapter, removing the spurious File button that had been appearing during annotated screen captures (`2777bf82`).
- XerahS: A reentry bug in the editor confirmation overlay was fixed so that rapid confirm/cancel sequences no longer spawn duplicate dialog instances on top of each other (`d9e12fe7`).
- ShareX.ImageEditor: The editor's close-confirmation logic was guarded against reentry to match the same fix applied on the XerahS host side, preventing double-confirmation dialogs from opening in standalone editor mode (`d875b609`).
- ShareX.ImageEditor: `ContinueCommand` is now only executed when the editor is not in `ImageEditorMode`, preventing the command from triggering unwanted application-exit flows that were designed for the host-embedded path (`b4a51862`).

## Build and Tooling

- XerahS: The IEIP0006 proposal document was written and extended across four documentation commits on the same evening. The initial draft was added first, then updated to include the `ShareX.ImageEditor.Loader` host module context, and finally expanded with an alternatives section covering native JXL libraries as a potential future direction (`b8c5d845`, `15db19a0`, `2ea1a982`).
- XerahS: VS Code debug and MCP server configurations were committed for both the XerahS host and connected tooling, streamlining the local development experience for contributors using VS Code alongside Cursor (`e2c9f3e7`, `06ded3e0`).
- ShareX.ImageEditor: Toolbar layout received visual attention alongside the behaviour changes. The ZoomPicker layout was adjusted with an explicit zoom icon, the bottom panel's margin around the Zoom to Fit button was increased, and the crop confirm button's layout and cursor feedback were refined for a more polished feel (`432a6c39`, `f73c739b`).
