# XerahS Daily Blog Draft - 2026-03-17

Date: 2026-03-17
Time Zone: UTC+8
Status: Draft

## Summary

March 17 centered on two parallel tracks: the XIP0053 compiled-binding hardening push across XerahS and ShareX.ImageEditor, and a new clipboard monitoring workflow that quickly expanded into Linux menu, focus, and window-activation fixes. XerahS enabled compiled bindings by default, tightened ViewLocator and template wiring, added CI and documentation guardrails, and introduced a cross-platform clipboard monitor abstraction with Linux, Windows, and macOS registrations plus a user-facing Integration-tab toggle.

The rest of the day was heavy on follow-up stabilization. Linux clipboard polling stopped dismissing menus or hanging Upload Content flows, clipboard monitoring stopped stealing focus while menus were open, menu command bindings were repaired across compiled-binding startup paths, tool windows were brought back above the main window after menu navigation, and ShareX.ImageEditor mirrored the compiled-binding rollout while adding opt-in clipboard auto-copy behaviors for initial images and later edits.

## Features

- Added clipboard monitoring as a cross-platform integration service in XerahS, with shared app-level wiring plus Linux, Windows, and macOS platform registrations for monitoring clipboard changes.
- Added a user-facing clipboard monitoring toggle under Application Settings > Integration and moved system settings into that same integration area so host-facing options live together.
- ShareX.ImageEditor added host-controlled clipboard behaviors that can copy the initial image and later edits back to the clipboard automatically, while keeping auto-copy disabled by default so hosts can opt in deliberately.

## Fixes

- Completed the XIP0053 rollout in XerahS by enabling compiled bindings by default, fixing typed binding regressions across multiple views, and hardening `ViewLocator` with explicit view-model mappings.
- Prevented Linux clipboard-related failures by fixing async delegation deadlocks, avoiding Upload Content hangs, and switching menu-sensitive clipboard polling to a lightweight type-list fingerprint so menus no longer dismiss immediately.
- Stopped clipboard monitoring from stealing focus while menus are open and repaired broken menu bar command bindings plus startup binding regressions across platforms after the compiled-binding changes.
- Improved window and tool activation flows by fixing upload window activation and ensuring tool windows are brought back above the main window after menu-driven navigation.

## Build and Tooling

- Added the `XIP0053` compiled-binding hardening proposal, a dedicated CI guardrail workflow and checker script, and follow-up documentation that clarifies Avalonia binding guidance plus the menu fallback scope.
- Updated `Directory.Build.props` during the same hardening pass so shared build settings stay aligned with the stricter binding rollout.
- ShareX.ImageEditor enabled compiled bindings by default with an editor compatibility opt-out, then finalized the template and control fixes needed for the stricter binding mode.
