# XerahS Daily Blog Draft - 2026-03-18

Date: 2026-03-18
Time Zone: UTC+8
Status: Draft

## Summary

March 18 focused on two connected areas: tightening XerahS capture and recording workflows, and pulling more of the image-effects authoring experience into the main app. Recorder workflows now reuse saved regions more reliably, stop requests reach active sessions correctly, CLI duration handling applies across the broader ScreenRecorder workflow family, and Task Settings can open the refactored ImageEditor effect browser while offering richer property editing and preview behavior.

ShareX.ImageEditor moved in parallel on both features and UI infrastructure. The editor added a new text watermark effect and dialog, centralized shared styles and typography resources, introduced animated popup and sidebar styling, and removed its app-specific HostIcons surface after that ownership moved into XerahS UI.

## Features

- XerahS upgraded Task Settings image-effect authoring by reusing the refactored ImageEditor effect browser as a modal picker and by bringing ImageEditor-style property editing and preview heuristics into workflow configuration.
- ShareX.ImageEditor added a text watermark effect with token expansion, placement and styling controls, preview/apply hooks, and a dedicated dialog so annotated text watermarks can be composed directly in the editor.
- XerahS took ownership of the HostIcons surface inside `XerahS.UI`, which lets host-specific navigation and theming stay in the app while the shared editor library remains app-agnostic.

## Fixes

- Fixed recorder workflow correctness in XerahS by prompting for a custom region when none is configured, persisting the selected bounds, routing recorder-start workflows back to the saved last region, wiring StopScreenRecording through active session signaling, and extending CLI duration auto-stop coverage across recorder job variants.
- Restored Task Settings Add Effect enumeration so supported effects without parameterless constructors appear again, then removed workflow image-settings dead space and normalized effect property controls to the XerahS theme.
- Defaulted clipboard monitoring to disabled for new configs and hardened plugin-folder cleanup so bundled and user plugin roots are cleaned consistently without unsafe foreground deletion behavior.

## Build and Tooling

- ShareX.ImageEditor centralized editor presentation infrastructure by moving shared control styles into `ShareXStyles.axaml`, inlining typography resources into `ShareXTheme.axaml`, scoping the style include to `EditorView`, and adding reusable popup, chevron, sidebar, and overlay animation classes.
- XerahS updated the `ShareX.ImageEditor` submodule in two steps to pick up the editor popup/style refactor first and then the follow-up `HostIcons` removal after icon ownership moved into `XerahS.UI`.
- Follow-up theming polish in ShareX.ImageEditor widened the sidebar, adjusted upward zoom popup behavior, and replaced hardcoded dialog colors with shared `TextBox` and `CheckBox` styles so host and editor visuals stay aligned.
