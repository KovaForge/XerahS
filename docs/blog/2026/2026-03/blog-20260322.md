## Summary

March 22 started with a focused after-capture workflow fix, but it quickly expanded into a broader platform and packaging day. XerahS added MSI packaging via WiX, built out reusable AUR packaging and Linux install docs, hardened Linux startup and hotkey fallbacks, corrected upload and plugin-path edge cases, and overhauled the Imgur OAuth flow so login behaves more predictably across platforms. ShareX.ImageEditor advanced in parallel with EffectBrowser UX improvements, a new line drawing effect, and persistence for the last used annotation tool, while ShareX.VideoEditor and XerahS.Editor were both checked and had no matching UTC+8 commits.

## Features

- XerahS: The Imgur plugin moved to a token-based OAuth flow (`630749d0`) and later refined the login UX and default client ID handling (`6cba98fd`), making the configuration surface more explicit and the authorization path more reliable across fresh and migrated setups.
- XerahS: Windows packaging gained first-class MSI installer generation via WiX alongside the existing EXE path (`a948921e`), expanding the release artifacts that can be produced from the main release workflow.
- ShareX.ImageEditor: EffectBrowser work continued with recent-effects tracking (`54cd91d9`), a search watermark that shows effect counts (`e847dd2e`), a simplified favorites empty state (`8f7f1331`), and a category cleanup that moved Wooden Frame into Filters (`faca6a56`).
- ShareX.ImageEditor: A new line drawing effect and dialog landed (`7d30bbca`), and the editor now remembers and restores the last used annotation tool (`5a29f102`) so repeated editing sessions start closer to the user's previous context.

## Fixes

- XerahS: The `AfterCaptureWindow` cancellation now correctly suppresses the post-task toast notification (`51dc50ae`). Previously, cancelling the window mid-flow still triggered the "task complete" toast, misleading users into thinking their capture had been uploaded or processed. The fix threads a cancellation state through `IJobProcessor`, `FinalizationStage`, `CaptureJobProcessor`, and `UploadJobProcessor` so all downstream stages see the cancellation and skip toast emission.
- XerahS: Upload fallback routing from the generic File category back to the Image category was corrected (`3aceb524`), preventing image-oriented workflows from silently falling onto the wrong upload path when the primary category choice could not be used.
- XerahS: Linux hotkey and capture behavior received two related fixes: portal bind cancellations with `response=1` now activate the X11 fallback instead of leaving hotkeys dead for the session (`0939672f`), and hotkey-triggered captures once again honor the selected Linux region selector preference (`ee254f7b`).
- XerahS: System-installed Linux builds were hardened against startup failures by always creating the personal Plugins directory instead of trying to create a write-protected system path (`fb1c443b`). A follow-up app-level guard (`e65bcc56`) prevents Avalonia `TaskCanceledException` failures from DBus from crashing the process, complementing earlier DBus exception cleanup work on the same day.
- XerahS: The Imgur integration also picked up two corrective follow-ups: OAuth browser launch now goes through cross-platform URL helper logic (`656e2975`), and the login UX / client ID defaults were cleaned up (`6cba98fd`) so configuration behaves more sanely for both new and migrated users.

## Build and Tooling

- XerahS: MSI packaging support was added to the release pipeline (`a948921e`) with a new WiX source file, expanded Windows packaging script, workflow updates, and release-asset validation support so MSI and EXE installers can be produced side by side.
- XerahS: Linux distribution tooling grew substantially. A reusable AUR packaging script and `xerahs-git` `PKGBUILD` were added (`06fff733`), the package definition absorbed upstream improvements such as Wayland/X11 optional dependencies and modern icon installation paths (`ec08bbb0`), and the packaging script was tightened to clean up build artifacts between runs (`9811d0a5`).
- XerahS: Contributor docs were updated to match that packaging work: a dedicated Linux install guide was added (`fb6ec404`), and `PLUGIN_SDK.md` was moved into `developers/guidelines/` (`e4e407ea`) so plugin-author guidance sits with the rest of the developer workflow docs.
- XerahS: Release automation continued moving toward shell parity on this day. The v0.20.15 release commit (`44e0d3c3`) added shell-script companions for several automation skills, including `draft-blog-post`, `update-changelog`, uploader-plugin scaffolding, and XIP sync helpers.
- XerahS: v0.20.15 and v0.20.16 were both cut on this day (`44e0d3c3`, `bb93eb2d`), reflecting how quickly packaging and RegionCapture follow-up work was being folded back into releasable builds.
