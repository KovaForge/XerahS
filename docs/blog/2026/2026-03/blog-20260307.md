# XerahS Daily Blog Draft - 2026-03-07

Date: 2026-03-07
Time Zone: UTC+8
Status: Draft

## Summary

Pulled ShareX.ImageEditor into the XerahS repo for the first time, wired up the new ShareX.VideoEditor submodule, and started integrating the video editor into the desktop UI. Also iterated quickly on Linux region capture (Wayland/X11) and portal behavior to keep cross‑platform capture solid while the new tools came online.

## Features

- Wired the first end‑to‑end integration of ShareX.VideoEditor into XerahS, including new `WorkflowType.VideoEditor`, `ShowVideoEditorAsync` hooks, and navigation entries in the Tools menu and sidebar.
- Introduced the AnnotateMedia workflow so image/video annotation can route to either the ImageEditor or the VideoEditor depending on file type.
- Added the ShareX.ImageEditor (Avalonia) codebase into the repository as an `ImageEditor/` subtree so we can iterate on the editor alongside XerahS.

## Fixes

- Hardened Linux region capture across X11, Wayland, and KDE by fixing crop bounds, physical‑resolution handling, and overlay positioning.
- Resolved several VideoEditor startup and host‑UI issues so the tool can be launched reliably from XerahS without crashes or missing assets.
- Fixed GNOME portal recording output handling and double region‑selection prompts when recording via the XDG portal.

## Build and Tooling

- Added and wired the ShareX.VideoEditor submodule into the desktop solution, making it part of the standard developer bootstrap.
- Updated FFMPEG documentation and supporting scripts so local dev and packaging flows understand the new VideoEditor dependencies.
