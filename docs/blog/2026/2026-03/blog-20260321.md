# XerahS Daily Blog Draft - 2026-03-21

Date: 2026-03-21
Time Zone: UTC+8
Status: Draft

## Summary

March 21 was a milestone day on two fronts. In ShareX.ImageEditor, the IEIP0003 schema-driven filter catalog work came to a head: all 77 existing image filters were migrated to a new catalog-driven architecture, and 152 bespoke per-filter dialog files were deleted in one commit — a sweeping cleanup that dramatically reduces the boilerplate maintenance cost of adding new effects. In XerahS proper, IEIP0002 shipped: the Tool Info panel feature was fully implemented in RegionCapture, wired through a dedicated ToolInfo adapter in `RegionCaptureAnnotationViewModel`, and merged as pull request #197. The day also included a v0.20.11 release, a v0.20.12 hotfix, macOS build improvement, a UI fix for cross-platform icon rendering, and VideoEditor submodule bumps for Tailwind and playback.

## Features

- XerahS: IEIP0002 Tool Info panel is now live in RegionCapture. A `ToolInfoAdapter` was implemented in `RegionCaptureAnnotationViewModel` to supply live tool-metadata to the panel, and the feature was merged to the main branch via PR #197. The panel was visually toned down after an initial review to avoid overshadowing the annotation canvas.
- XerahS: Creative ImageEditor filters landed in XerahS (`80eca12f`) with full dialog wiring tests (`CreativeFilterDialogWiringTests`) to verify that filter dialogs load, commit, and cancel correctly through the shared presenter contract.
- XerahS: The ViewLocator was extended (`3cc83c40`) to resolve cross-assembly view/viewmodel pairs, allowing views from separate assemblies (e.g. the ImageEditor plugin) to be resolved without registration boilerplate. New `ViewLocatorTests` cover the cross-assembly path.
- ShareX.ImageEditor: IEIP0003 schema-driven filter catalog was completed. All 77 filters were migrated from hand-authored dialogs to catalog entries that derive their UI from a shared schema. The 152 now-redundant dialog files were deleted in a single commit (`2496c20`), cutting thousands of lines of filter-dialog boilerplate.
- ShareX.ImageEditor: New procedural image filters and dialogs were added (`04f6d4c`), continuing the expansion of the effect library as old-style dialogs were being phased out.
- ShareX.ImageEditor: Toolbar-button styling was centralized into a new `ImageEditorStyles` resource (`108290c`) so button dimensions, shapes, and hover states are defined once and referenced from both the main editor toolbar and the annotation surface.

## Fixes

- XerahS: Resolved a cross-assembly view registration failure in `ViewLocator.cs` that prevented views defined in plugin or shared-UI assemblies from being resolved at runtime. Tests were added to lock down the fix.
- XerahS: macOS native dylib rebuild was skipped when source files are unchanged (`ae83aaa7`), eliminating interactive Xcode license prompts on machines where the dylib is already up to date. `Inputs`/`Outputs` MSBuild target attributes now gate the `make` call on source freshness.
- XerahS: Emoji glyphs in the History and Provider Explorer view toggle buttons were replaced with Lucide font icons (`a19afd49`). Emoji characters (`≡ƒôï`, `≡ƒö▓`, `Γ¼å`, `≡ƒöä`) do not render reliably on macOS, showing placeholder boxes; the fix switches to `U+E1D1` (list-ordered) and `U+E4FF` (grid-2x2) Lucide glyphs and removes the unused `ViewToggleConverter`.
- XerahS: RegionCapture toolbar regression introduced in the v0.20.11 release was hotfixed in v0.20.12 (`96ea1075`) by restoring missing XAML in `OverlayWindow.axaml` that was dropped during the ToolInfo merge.
- ShareX.ImageEditor: Button margins and layout in `EditorView.axaml` were aligned with the reference commit (`f831028`) to keep the editor visually consistent after the toolbar-style consolidation.

## Notes

- The v0.20.12 hotfix shortly after v0.20.11 was a direct consequence of the ToolInfo merge removing a critical XAML node in `OverlayWindow.axaml`; the `publish-release` skill change to default to pre-release is a mitigating measure to keep regressions from reaching stable users before a wider soak.
- The IEIP0003 migration deleted 152 files in a single commit — this is the kind of structural change that benefits from a clean post-migration test pass to confirm all 77 effects still render and apply correctly through the new catalog path.
- Cross-assembly view resolution in `ViewLocator` is an architectural enabler for future plugin or shared-UI scenarios; the new test coverage should be kept up to date as new assemblies are added to the build.
- Emoji-to-Lucide icon migration (History/Explorer toggle) surfaces a broader cross-platform rendering concern — any remaining emoji in XerahS UI surfaces should be audited for similar macOS rendering gaps.
