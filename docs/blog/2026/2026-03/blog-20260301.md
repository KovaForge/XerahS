## Summary

Shipped the v0.19.0 desktop release and immediately followed it with a round of Linux recording, path, and update-check fixes, focusing on making screen capture and error handling feel solid across platforms.

## Features

- Centralized log and error paths through `PathsManager`, funneling errors into a predictable `XerahS-errors-yyyyMMdd.log` file and documenting the new layout so troubleshooting is easier.

## Fixes

- Tightened Linux recording behavior by correcting GStreamer caps negotiation, adding a GL→CPU fallback path, and fixing region crop squashing in the pipeline.
- Cleaned up Linux recording portal sessions on fatal errors to avoid unobserved exceptions and improve reliability after failures.
- Fixed the tray stop button and hotkey-driven recording stop logic so recordings can be cancelled consistently from both UI and hotkeys.
- Corrected DXGI rotation mapping for rotated monitors and fixed GitHub update-check JSON and log file naming so updates and logs behave as expected.
- Improved `PluginLoadContext` shared-dependency detection to reduce subtle plugin loading issues.

## Build and Tooling

- Completed the v0.19.0 release flow and associated maintenance tasks, including CI release jobs and path audits for logs and troubleshooting output.
- Added a `run-debug-app.sh` helper script to streamline running XerahS under debug on Unix-like environments.
