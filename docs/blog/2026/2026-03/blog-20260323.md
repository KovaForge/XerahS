Date: 2026-03-23

## Summary

March 23 was a feature-heavy editor day paired with two Linux-focused correctness fixes in XerahS. ShareX.ImageEditor shipped a substantial wave of new image effects and EffectBrowser usability work, including background removal, edge feathering, inner shadow support, stronger spotlight presets, better nebula rendering, and clearer category hints. XerahS itself stayed narrowly focused on platform parity by fixing the Linux "Add from Catalog" modal path and aligning overlay capture behavior with the Windows transparent-overlay option, while XerahS.Editor was checked and had no matching UTC+8 commits.

## Features

- ShareX.ImageEditor: The biggest addition was a new Remove background image effect (`9447b8e`) backed by a full background-removal pipeline with border sampling, prototype clustering, affinity scoring, mask generation, and optional feathering and blur. A follow-up registration commit (`cfc85c1`) placed the effect into the correct Manipulations area in the UI and kept it out of the generic Filters listing.
- ShareX.ImageEditor: Filter work continued with a new Edge Feather effect (`9fa27d3`) plus a new Inner Shadow filter (`4d1ea16`) that introduced an inward shadow implementation, numeric X/Y offsets, and a larger numeric control surface for shadow tuning. The next commit (`6c1eaa1`) expanded the inner-shadow size ceiling to 300 so stronger looks are possible without code changes.
- ShareX.ImageEditor: EffectBrowser usability improved in multiple small but visible ways. Category headers gained a dedicated hint icon and tooltip (`81887ef`), recent effects can now be removed with a right-click action (`52de63c`), and spotlight mementos were enabled with stronger defaults (`370fae9`) to make effect exploration more discoverable.
- ShareX.ImageEditor: Visual polish work also continued in the effect stack with improved nebula star twinkle and streak rendering (`4a439db`), extending the day's editor work beyond new filters into better procedural output quality.

## Fixes

- XerahS: The Linux "Add from Catalog" path was fixed by dispatching modal-open state changes onto the Avalonia UI thread (`326d104`). This addressed a platform-specific case where the command updated modal state synchronously but the visual tree did not repaint, leaving the button looking unresponsive on Linux while it still worked on Windows.
- XerahS: Overlay capture behavior was brought back into line with Windows for feature parity (`4688c13`). The Linux path no longer forces the fast overlay unconditionally, so `UseTransparentOverlay` now controls the capture overlay in a cross-platform-consistent way.

## Build and Tooling

- XerahS, ShareX.ImageEditor, and XerahS.Editor: No build, packaging, CI, or documentation-infrastructure commits were identified for this UTC+8 day. The work tracked here was concentrated on runtime fixes and editor feature delivery rather than tooling changes.
