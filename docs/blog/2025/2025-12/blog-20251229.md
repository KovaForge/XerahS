# XerahS Daily Blog Draft - 2025-12-29

Date: 2025-12-29
Time Zone: UTC+8
Status: Draft

## Summary

Kicked off the port of classic ShareX into a new Avalonia-based XerahS shell by scaffolding the solution, wiring common helpers, and starting to pull over core backends like indexing, history, media, and uploaders. Most of the day was spent building the foundation: shared types, math utilities, logging, and the first wave of ImageEffects and media helpers.

## Features

- Stood up the initial Avalonia solution and common helper layer, including logging, math and point types, CLI helpers, and platform-neutral data utilities that everything else will sit on.
- Ported the first slice of media and capture backend, including partial screen-capture helpers, ffmpeg option wiring, and file-history plumbing needed for a ShareX-like workflow.
- Brought over a broad set of ImageEffects operations (resize, rotate, crop, blur, sharpen, canvas, rounded corners, watermarks, pixelate, convolution filters) so the future editor has a rich toolbox to build on.
- Seeded uploader and history models (uploader settings, FTP accounts, history settings, upload stubs) so the eventual automation and upload flows have a domain model ready.

## Fixes

- Smoothed over early porting gaps by aligning URL prefix helpers with the classic ShareX behavior and fixing naming conflicts in default-value helpers as code moved into the new namespaces.
- Tightened translator and ImageEffects adjustments so the first batch of image processing ports actually builds and behaves like their WinForms predecessors.

## Build and Tooling

- Added and organized a large suite of common helpers (registry, HTTP/downloaders, DPAPI JSON encryption, folder tokens/variables, media helpers, unsafe bitmap utilities) into shared libraries that can be reused across XerahS, ImageEditor, and future tooling.
- Updated the backend gap report and porting checklist to reflect which helpers, backends, and effect pipelines are now live in the Avalonia projects, making it easier to track what’s left.
